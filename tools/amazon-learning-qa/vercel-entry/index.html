Vercel 边界

本页可以部署到 Vercel，但它不是云端完整问答服务。完整问答依赖本机文件、Ollama、本地数据库和 openhuman-core 长驻进程，因此不能原样在 Vercel Serverless 环境中运行。

如果要做真正云端版，需要先把数据库、模型服务和核心进程迁到可长驻的云端服务。

本机启动方式

  1. 确认 Ollama 正在运行，并已安装本地向量模型。
  2. 在仓库内运行：node tools/amazon-learning-qa/amazon-qa-product.mjs start
  3. 打开：http://127.0.0.1:7790
  4. 运行：node tools/amazon-learning-qa/amazon-qa-product.mjs doctor 检查状态。

验收方式

  • 运行 node tools/amazon-learning-qa/amazon-qa-product.mjs acceptance。
  • 检查三类真实问题、主图追问、换题不串题和结果反馈再追问。
  • 确认来源引用、图谱、学习队列、学习包、复习卡和行动实验计划都返回结果。
  • 来源树仍在后台深加工，按最近速度约 5 天；这不影响当前问答和引用。
本页不包含音频或视频功能。它只说明当前本地产品交付状态、验收方式和远程发布边界。
