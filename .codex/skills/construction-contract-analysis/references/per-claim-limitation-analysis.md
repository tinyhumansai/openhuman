# 逐笔债权时效分析

## 概述

建设工程合同纠纷中，工程款通常分期支付（预付款、进度款、结算款、质保金）。每笔付款构成独立的债权，有独立的诉讼时效起算点。**不得笼统以"最后一笔付款"作为全部债权的时效基准。**

## 核心规则

### 独立债权原则

每一期工程进度款/结算款是一个独立的债权，各自受到独立的诉讼时效约束。

### 时效起算规则

| 债权类型 | 时效起算时点 | 依据 |
|---------|------------|------|
| 预付款 | 合同约定的预付日期 + 应付未付次日 | 合同条款 |
| 进度款 | 每期审核通过后约定的支付日 + 应付未付次日 | 合同付款条款 |
| 结算款 | 竣工结算完成后的约定支付日 + 应付未付次日 | 合同结算条款 |
| 质保金 | 缺陷责任期届满后的约定返还日 + 应付未付次日 | 合同质保金条款 |
| 变更签证款 | 变更签证审批通过后的约定支付日 + 应付未付次日 | 合同变更条款 |

### 时效中断事由

根据《民法典》第195条 [法条原文]：
1. 权利人向义务人提出履行请求（书面催款函送达）
2. 义务人同意履行义务（书面承诺、部分付款等）
3. 权利人提起诉讼或者申请仲裁
4. 与提起诉讼或者申请仲裁具有同等效力的其他情形

**部分付款的效力**：部分付款构成对债务的承认，导致剩余债务的时效中断。但该中断效果覆盖的范围（仅该笔债权还是全部债权）存在争议，建议逐笔分析。

|------|---------|---------|---------|-----------|------------|---------|------|

| 状态 | 债权数量 | 合计金额 | 占比 |

## 禁止行为

| 禁止 | 原因 |
|------|------|
| ❌ 笼统以"最后一笔付款"作为全部债权时效基准 | 每笔进度款是独立债权 |
| ❌ 假设"部分付款中断全部债权时效" | 该推定存在争议 |
| ❌ 只标注最后一笔付款的时效 | 必须逐笔分析 |
| ❌ 用"粗略估算"代替逐笔计算 | 时效计算必须精确到日 |
| ❌ 时效风险标注为"常规"（除非全部债权时效中断证据充分） | 时效是致命程序风险 |
