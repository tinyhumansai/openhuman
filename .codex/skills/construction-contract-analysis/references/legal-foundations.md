## 三、利息计算标准规则

### 计息起算规则

1. **合同有约定付款期限** → 严格按约定付款日次日起算
2. **合同无约定** → 按以下顺序确定起算日：
   - 工程实际交付之日
   - 提交竣工结算文件之日
   - 当事人起诉之日
3. **付款前置条件未满足** → 以前置条件完成日为实际起算日（司法实践支持）

### 利率适用规则

| 时段 | 适用利率 | 说明 |
|------|---------|------|
| 2019.8.19 及之前 | 中国人民银行同期同类贷款基准利率 | 1年以内按 1 年期 |
| 2019.8.20 及之后 | 全国银行间同业拆借中心公布的 LPR | 分段适用各期 LPR |

### 计息本金

- 以**实际应付净额**为计息本金（扣除合法扣款：质保金暂扣、甲供材、水电费、罚款等）
- 部分付款的按"先抵利息后抵本金"的司法清偿顺序处理

### 违约金上限（30% 规则）

- 约定的违约金超过造成损失的 30% → 可申请适当减少（民法典第 585 条）
- 逾期付款利息 + 违约金 → 总额不超过按年利率 24% 计算的金额（部分法院观点）
- 施工合同中专用规则：逾期竣工违约金一般不适用 30% 上限（因工期延误损失难以精确量化）

## 四、合同效力判断框架

### 无效情形（司法解释一第 1 条）

| 情形 | 后果 |
|------|------|
| 承包人未取得建筑业企业资质 | 合同无效 |
| 承包人超越资质等级 | 合同无效（竣工前取得相应资质除外）|
| 实际施工人借用有资质企业名义（挂靠） | 合同无效 |
| 必须招标而未招标或中标无效 | 合同无效 |
| 转包 | 合同无效 |
| 违法分包 | 合同无效 |

### 合同无效后的处理

- 工程经验收合格 → 参照合同约定折价补偿承包人
- 工程验收不合格 → 修复后合格，修复费由承包人承担；修复后仍不合格 → 无权请求折价补偿
- 发包人对不合格有过错的 → 承担相应民事责任

## 六、损失/违约金计算速查

### 停工损失（承包方向发包方索赔）

| 损失类型 | 计算方式 |
|---------|---------|
| 人员窝工费 | 现场施工及管理人员工日数 × 工日单价 |
| 机械闲置费 | 停滞机械台班 × 停滞台班费（或租赁费） |
| 材料积压损失 | 已购材料资金占用利息 + 仓储保管费 |
| 管理费 | 停工期间现场管理费实际支出 |
| 周转材料 | 租赁费用（模板/脚手架等） |

### 工期违约金（发包方向承包方索赔）

- 逾期天数 × 每日违约金标准（合同中约定，通常为合同价款的万分之三到万分之五）
- 法院调整原则：违约金总额一般不超合同价款的 5%（部分地区参考）

### 价款优先受偿权

- 范围：工程价款（含工作人员报酬、材料款等实际支出费用）
- 不含：逾期利息、违约金、损害赔偿金
- 行使期限：自发包人应当给付工程价款之日起 18 个月
- 效力：优先于抵押权和其他债权
- 放弃限制：放弃损害建筑工人利益的，放弃行为无效（司法解释一第 42 条）

## 七、民法典合同编通则补充规则

> 本节为合同编通则中与施工合同审查密切相关的高频规则速查。完整合同编通则体系可后续从 claude-for-legal-ZH 仓库引入 `contract-law-core.md`（496行），作为独立 reference 文件。

### 7.1 格式条款规制（民法典第496-498条）

施工合同多采用发包人提供的格式文本（如住建部示范文本基础上的修改版），格式条款规制尤为重要。

**提示说明义务**（第496条）：提供格式条款一方应采取合理方式提示对方注意免除或减轻其责任等与对方有重大利害关系的条款。未履行义务的，对方可主张该条款不成为合同内容。`[法条原文]`

**无效情形**（第497条）：不合理地免除或减轻提供方责任、加重对方责任、限制对方主要权利的格式条款无效。`[法条原文]`

**不利解释规则**（第498条）：格式条款有两种以上解释的，应作出不利于提供方的解释。`[法条原文]`

**施工合同专项适用**：
- 合同中"发包人不承担任何停工损失"类条款可能构成无效格式条款
- "最终解释权归发包人"类条款不具法律效力
- 承包人主张格式条款无效时的举证要点：证明该条款未经协商、内容显失公平

### 7.2 情势变更与不可抗力在施工合同中的应用

**不可抗力**（第180条/第590条）：不能预见、不能避免且不能克服的客观情况。因不可抗力不能履行合同的，部分或全部免责。`[法条原文]`

**情势变更**（第533条）：合同基础条件发生无法预见、非商业风险的重大变化，继续履行显失公平的，可请求变更或解除合同。`[法条原文]`

**施工合同高频场景**：

| 情形 | 定性 | 核心考量 |
|------|------|---------|
| 主要建材价格暴涨（超过预期的15%以上） | 情势变更 | 是否超出正常商业风险；是否已约定价格调整机制 |
| 政府环保管控导致停工 | 不可抗力 or 情势变更 | 管控范围/持续时间/是否可申请复工 |
| 疫情封控导致停工 | 不可抗力 | 具体封控时段/对施工的实际影响 |
| 规划调整导致设计变更 | 发包人责任 | 属发包人应提供的施工条件变化 |

### 7.3 违约金调整规则（民法典第585条）

> 约定的违约金过分高于造成的损失的，人民法院可以根据当事人的请求予以适当减少。`[法条原文]`

**施工合同专项适用**：
- 逾期竣工违约金："超过造成损失30%"的司法调整标准在工期延误场景中应谨慎适用
- 逾期付款违约金：可参照LPR四倍为调整参考线
- 违约金调整须依当事人请求——法院不得主动调整
- 多份合同违约金约定不一致时：以实际履行的合同为准

### 7.4 减损义务（民法典第591条）

> 一方违约后，对方应采取适当措施防止损失扩大；未采取适当措施致使损失扩大的，不得就扩大的损失请求赔偿。`[法条原文]`

**施工合同核心场景**：
- 发包人停建后，承包人应及时撤场减损——继续施工导致的扩大损失不予赔偿
- 发现质量问题后，发包人应及时通知并采取防护措施——任由损害扩大的部分由发包人自担
- 承包人被拖欠进度款后，应通过催告/停工/解除等合理方式减损

### 7.5 债务抵销（民法典第568-569条）

> 当事人互负债务，该债务的标的物种类、品质相同的，任何一方可以将自己的债务与对方的到期债务抵销。`[法条原文]`

**施工合同适用**：
- 发包人以质量缺陷修复费用抵销工程款——需修复费用金额确定
- 发包人以工期违约金抵销工程款——需违约金金额可计算
- 法定抵销的条件：互负债务 + 种类相同（均为金钱债务）+ 均已到期
- 主张抵销的一方应通知对方，通知到达对方时生效

## 八、2025年司法解释二（征求意见稿）核心变化速查 ★

> 最高人民法院于2025年11月23日发布《关于审理建设工程施工合同纠纷案件适用法律问题的解释（二）（征求意见稿）》。以下为核心变化速查，所有引用标注 `[征求意见稿]` `[未生效]`。

### 8.1 合同效力新规则

| 规则 | 内容 |
|------|------|
| 招标项目性质变化 | 起诉时已不属必须招标范围的，不因未招标认定合同无效 |
| 劳务分包/小型工程 | 三类工程无需资质：劳务分包、住宅室内装修（不涉及主体结构）、限额以下小型工程 |
| 先定后招 | 标前就实质性内容谈判且参与者中标的，合同无效 |

### 8.2 挂靠与转包新规则

| 规则 | 内容 |
|------|------|
| 管理费不受保护 | 出借资质合同无效，管理费不予支持 |
| 发包人知情挂靠 | 发包人知道或应知挂靠的，实际施工人可直接向其主张 |
| 表见代理加重 | 挂靠人以出借企业名义对外交易，符合表见代理的，出借企业担责 |

### 8.3 实际施工人维权路径收窄

| 规则 | 内容 |
|------|------|
| 回归合同相对性 | 多层转包/违法分包中的实际施工人不得直接起诉发包人 |
| 代位权优先 | 实际施工人应通过代位权（民法典第535条）向发包人追索 |
| 农民工例外 | 农民工工资仍可依《保障农民工工资支付条例》直接追索 |

### 8.4 价款结算新规则

| 规则 | 内容 |
|------|------|
| 固定总价不调价 | 固定总价合同原则上不调价，仅情势变更可调整 |
| 结算协议独立性 | 合同无效不影响结算协议效力 |
| 未完工程比例法 | 合同解除后未竣工工程按"已施工比例×固定总价"结算 |
| 质保金起算 | 合同无效/解除时，质保金从退场日或判决生效日起算 |
| 审计不当然约束 | 未约定审计条款的，不得以审计为结算依据；审计久拖不决可申请鉴定 |

### 8.5 优先受偿权新规则

| 规则 | 内容 |
|------|------|
| 停窝工损失 | 停窝工损失（农民工工资除外）不享有优先受偿权 |
| 工程毁损 | 可就保险金、赔偿款主张优先受偿 |
| 消费者购房人 | 住宅已转让给商品房消费者的，不支持优先受偿权 |

### 8.6 程序新规则

| 规则 | 内容 |
|------|------|
| EPC专属管辖 | EPC总承包合同由工程所在地法院专属管辖 |
| 劳务分包专属管辖 | 劳务分包合同纠纷由工程所在地法院专属管辖 |
| 移送行政主管 | 法院发现出借资质/转包/违法分包的，应移送行政主管部门 |
