# 模块四：四大核心争议焦点研判

## 触发条件

用户提到：争议、价款争议、工期争议、质量争议、违约争议、结算纠纷、延误责任、质量瑕疵、违约金调整

## 一、价款争议研判

### 研判框架

```
厘清计价模式 → 确定结算依据 → 核定已完工程量 → 核算应付款项 → 确定欠付金额
```

### 核心争议点

| 争议类型 | 关键问题 | 裁判倾向 |
|---------|---------|---------|
| 固定总价 vs 固定单价认定 | 合同对计价方式的表述是否清晰 | 合同约定优先，模糊时按实际履行 |
| 增量价款结算 | 变更/签证是否书面确认 | 有书面确认的支持；无书面但业主实际接受的可支持 |
| 超付/欠付认定 | 付款与工程进度的对应关系 | 以实际已完合格工程量为准 |
| 材料涨价调价 | 是否构成情势变更 | 异常波动可调整，一般波动不支持 |
| 司法鉴定必要性 | 双方结算差异是否可协商解决 | 差异大且无法协商时申请鉴定 |

## 二、工期争议研判

### 责任划分框架

```
列出所有延误事件 → 逐事件分析原因归属 → 区分顺延和非顺延 → 确定各方应承担的延误天数
```

### 延误原因归属

| 原因类型 | 归属方 | 是否顺延工期 | 是否赔偿 |
|---------|--------|------------|---------|
| 发包人原因（未提供场地/图纸/材料等） | 发包人 | 是 | 发包人赔偿承包人 |
| 承包人原因（施工组织不力/人员不足等） | 承包人 | 否 | 承包人承担违约金 |
| 第三方原因（设计变更/政府行为等） | 视情况 | 可能 | 视合同约定 |
| 不可抗力（疫情/极端天气等） | 双方 | 是 | 各自承担损失 |
| 同步延误（双方都有原因） | 按比例 | 部分 | 按过错比例 |

## 三、质量争议研判

### 研判框架

```
确定质量标准 → 鉴定质量事实 → 分析瑕疵成因 → 评估修复费用 → 判定是否影响付款
```

### 核心规则

1. **发包人擅自使用** → 视为质量合格（但地基基础和主体结构除外）
2. **质量瑕疵可抵扣** → 发包人可主张修复费用抵扣工程款
3. **严重质量问题** → 可拒绝接收并要求返工或解除合同

## 四、违约争议研判

### 双方过错叠加的处理

```
分别计算各方违约责任 → 判断是否存在违约叠加 → 适用抵消规则 → 确定净赔偿责任
```

### 违约金调整规则

- 违约金 > 损失的 130% → 可申请减少
- 违约金 < 损失的 70% → 可申请增加
- 施工合同工期违约金的调整空间小于一般民事合同

## 输出格式

每个争议类型输出：争议焦点一句话 → 事实查明 → 法律分析 → 结论建议


### 开工/竣工时间认定

#### 开工日认定规则

| 情形 | 认定规则 | 法律依据 |
|------|---------|---------|
| 有开工通知 | 开工通知载明的日期为开工日期 | 司法解释一第5条 |
| 无开工通知但有实际施工 | 实际进场施工日期为开工日期 | 司法解释一第5条 |
| 无证开工（未取得施工许可证） | 仍以开工通知或实际施工日为开工日（许可证属行政管理，不影响民事认定）| 司法解释一第5条 |
| 发包人/监理未签发出开工通知 | 以承包人实际进场施工日为开工日期 | 最高法裁判规则 |
| 承包人拖延进场 | 以开工通知载明日期为准，承包人承担延误责任 | |

#### 竣工日认定规则

| 情形 | 认定规则 | 法律依据 |
|------|---------|---------|
| 竣工验收合格 | 竣工验收合格之日为竣工日期 | 司法解释一第9条 |
| 发包人拖延验收 | 承包人提交验收报告之日为竣工日期 | 司法解释一第9条 |
| 未经验收擅自使用 | 发包人转移占有之日为竣工日期（但地基基础和主体结构除外）| 司法解释一第9条 |
| 已提交结算文件但发包人拖延审核 | 以结算文件提交日为竣工日（需合同有约定） | |

#### 常见争议点

- 发包人拖延验收：承包人需举证已提交验收申请和完整验收资料
- 擅自使用不等于质量免责：发包人擅自使用后仍可主张地基和主体结构质量问题
- 多单体工程的竣工日：一般按各单体分别认定，合同有约定从约定
- 甩项验收：发包人要求部分未完工先行使用的，竣工日为甩项验收合格日
