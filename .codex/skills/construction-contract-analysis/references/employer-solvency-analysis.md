# 发包方偿债能力分析与财产线索排查

## 概述

建设工程纠纷的最终目的是收回款项。法律分析如果只关注"能否打赢"而不关注"能否执行"和"如何查到财产"，是不完整的。本模块定义发包方偿债能力分析 + 财产线索系统排查的完整框架。

## 适用场景

触发 `construction-contract-analysis` 的争议研判（模块4）或成果输出（模块8）阶段时，如涉及承包人向发包方主张工程款，**必须**执行偿债能力分析和财产线索排查。

## 第一部分：主体信用分析

### 1. 主体性质

| 分析项 | 信息来源 | 法律意义 |
|--------|---------|---------|
| 法人类型 | 工商登记 | 有限责任公司/股份公司/机关法人/事业单位 |
| 注册资本 | 工商登记 | 原始偿债能力基准 |
| 实缴资本 | 工商登记 | 实际出资情况 |
| 股东结构 | 工商登记 | 实际控制人判断 |
| 是否为政府平台公司 | 工商登记+公开信息 | 适用隐性债务化解政策风险 |

### 2. 信用记录

| 分析项 | 信息来源 | 搜索方法 |
|--------|---------|----------|
| 被执行案件 | 中国执行信息公开网 | WebSearch "公司全名 被执行人" |
| 失信被执行人 | 最高法失信名单 | WebSearch "公司全名 失信" |
| 限制高消费 | 中国执行信息公开网 | WebSearch "公司全名 限制高消费" |
| 股权冻结 | 工商登记 | WebSearch "公司全名 股权冻结" |
| 终本案件 | 中国执行信息公开网 | WebSearch "公司全名 终本" |
| 破产/重整 | 全国企业破产重整案件信息网 | WebSearch "公司全名 破产 OR 重整" |

### 3. 偿债能力评级

| 等级 | 标准 | 对策建议 |
|------|------|---------|
| **良好** | 注册资本充足，无被执行记录，正常经营 | 可走正常诉讼+执行路径 |
| **一般** | 无被执行记录但资产状况不透明 | 建议诉讼中申请财产保全 |
| **关注** | 有少量被执行记录，可能有资产转移迹象 | 必须申请财产保全，优先追索 |
| **风险** | 多条被执行记录，可能资不抵债 | 考虑追加被执行人（如代建人连带、股东刺破等） |
| **高危** | 已被列为失信被执行人，可能已注销 | 及时起诉保全已有资产，考虑对高管/实际控制人追责 |

## 第二部分：财产线索系统排查方法论 ★核心★

### 排查总则

**三优先原则**：
1. **价值高 + 易查找**优先：土地使用权、房产（公开登记，价值集中）
2. **流动性高**优先：银行存款 > 应收账款 > 股权 > 不动产
3. **可快速保全**优先：银行账户（在线冻结）> 不动产（查封登记）> 股权（工商冻结）

**排查顺序**：先查公开登记财产（不动产/股权），再查隐蔽财产（应收账款/关联交易），最后查特殊财产（代建项目权益/政府补贴）。

### 财产类型一：不动产（土地使用权 + 房产）★★★ 最优先

这是政府平台公司最核心的财产，也是执行中最容易处置的资产。

| 搜索维度 | 搜索方法 | 搜索示例 |
|---------|---------|---------|
| **土地使用权** | WebSearch "公司名 土地" OR "土地使用权" | "西安高新区交通投资建设 土地" |
| | WebSearch "公司名 招拍挂" OR "土地出让" | 查找公司是否参与过土地出让程序 |
| | WebSearch "公司名 划拨" OR "划拨土地" | 平台公司常持有划拨用地 |
| **房产** | WebSearch "公司名 房产" OR "不动产" OR "房屋" | 查找是否持有办公楼、厂房、商业物业 |
| | WebSearch "公司名 项目 建筑面积" | 查找公司投资建设的项目及其规模 |
| | WebSearch "公司名 竣工验收" | 平台公司投资建设的项目竣工后可成为其资产 |
| **在建工程** | WebSearch "公司名 在建" OR "施工" OR "建设" | 查找正在开发的项目 |
| **租赁收入** | WebSearch "公司名 出租" OR "租赁" OR "租金" | 是否有对外出租的不动产产生稳定现金流 |

### 财产类型二：银行存款 ★★★

流动性最高，可在诉讼中通过法院在线查控系统快速冻结。

| 搜索维度 | 搜索方法 | 备注 |
|---------|---------|------|
| **基本户/一般户** | WebSearch "公司名 开户银行" OR "开户行" | 从招标文件/合同/发票中获取银行账号 |
| | 从本案EPC合同中直接获取 | 合同签署页通常记载开户银行和账号 |
| **财政专户** | WebSearch "公司名 财政" OR "非税收入" | 平台公司可能有财政专户（但通常不能冻结） |
| **招投标保证金账户** | 从招标文件中获取 | 招标文件通常指定保证金缴纳账户 |

### 财产类型三：应收账款 ★★

平台公司对政府/其他项目参与方的应收账款是重要的潜在财产。

| 搜索维度 | 搜索方法 | 备注 |
|---------|---------|------|
| **对政府部门的应收款** | WebSearch "公司名 回购" OR "购买服务" OR "委托代建" | 平台公司涉及代建项目，发包方对政府有代建费应收账款 |
| | 查阅代建协议 | 代建协议通常约定委托人（政府）向代建人（发包方）支付代建管理费 |
| **对关联方的应收款** | WebSearch "公司名 关联交易" OR "关联方" OR "子公司" | 查找母子公司间的资金往来 |
| **其他应收款** | WebSearch "公司名 应收账款" OR "其他应收款" | 结合公司财务报表/债券募集说明书 |
| **债券募集说明书**★ | WebSearch "公司名 募集说明书" OR "债券" OR "中期票据" | 债券发行的募集说明书详细披露公司财务数据，含应收账款明细 |

### 财产类型四：股权投资 ★★

平台公司通常持有多个子公司/参股公司的股权。

| 搜索维度 | 搜索方法 |
|---------|---------|
| **对外投资** | WebSearch "公司名 对外投资" OR "投资 公司" |
| **子公司** | WebSearch "公司名 下属" OR "全资" OR "控股" |
| **股权结构图** | WebSearch "公司名 股权结构" OR "股权穿透" |

### 财产类型五：车辆与设备 ★

| 搜索维度 | 搜索方法 |
|---------|---------|
| **车辆** | WebSearch "公司名 车牌" OR "车辆" |

### 财产类型六：代建项目权益 ★政府平台公司特有

这是平台公司最特殊的一类财产。

| 搜索维度 | 搜索方法 | 备注 |
|---------|---------|------|
| **待回购项目** | WebSearch "公司名 BT" OR "回购" | BT/代建模式下政府承诺回购的代建项目 |
| **在建代建项目** | WebSearch "公司名 代建" OR "委托代建" | 正在管理的代建项目，有未来的管理费收入 |
| **代建管理费** | 查阅代建协议 | 代建协议约定的管理费率 × 项目总投资 |

### 财产类型七：政府补贴与专项资金 ★平台公司特有

| 搜索维度 | 搜索方法 | 备注 |
|---------|---------|------|
| **财政补贴** | WebSearch "公司名 补贴" OR "财政拨款" OR "专项资金" | 平台公司接收的财政补贴信息常出现在债券募集说明书中 |
| **特殊再融资债券分配** | WebSearch "高新区 再融资债券" OR "置换债券" | 财政部发行的特殊再融资债券可能分配至平台公司用于置换隐债 |

## 第三部分：财产线索搜索的 Agent 执行指南 ★新增★

### 搜索轮次与并行策略

Agent 在执行财产线索排查时，应遵循以下分轮搜索策略：

**第一轮（信用排查，并行 4 路）**：
```
├── WebSearch "公司全名 被执行人"
├── WebSearch "公司全名 失信"
├── WebSearch "公司全名 破产 OR 重整"
└── WebSearch "公司全名 股权冻结"
```

**第二轮（实体财产排查，并行 5 路）**：
```
├── WebSearch "公司全名 土地" OR "土地使用权"
├── WebSearch "公司全名 房产" OR "不动产"
├── WebSearch "公司全名 对外投资" OR "子公司"
├── WebSearch "公司全名 债券" OR "中期票据" OR "募集说明书"
└── WebSearch "公司全名 委托代建" OR "回购" OR "代建管理费"
```

**第三轮（深挖，并行 3 路）**：
```
├── WebSearch "公司全名 财务报告" OR "审计报告" (如债券募集说明书未在第一轮搜到)
├── WebSearch "[控股股东全名] 融资" OR "[控股股东全名] 债务"
└── WebSearch "[所属开发区/区县] 平台公司" OR "[所属开发区/区县] 隐性债务"
```

**第四轮（裁量补充）**：
根据前三轮结果，针对发现的子公司/项目/资产进行精确搜索。

### 搜索陷阱规避

| 陷阱 | 规避方法 |
|------|---------|
| 公司简称/曾用名 | 搜索时同时使用全称、简称和曾用名 |
| 工商信息过期 | 标注检索日期，并提示"截至检索日期" |
| 裁判文书网搜索不全 | 同时搜索"天眼查/企查查/启信宝"（通过WebSearch间接抓取） |
| 政府平台公司的隐蔽资产 | 重点关注"代建协议""回购协议""财政补贴通知""土地划拨文件""债券募集说明书" |

## 第四部分：政府平台公司特殊风险

如发包方为政府平台公司（如各种"城投""交投""开发公司"），需额外关注：

- **隐性债务化解**：可能导致资产剥离或划转
- **平台清理/退出**：可能被合并、重组或注销
- **财政补贴依赖**：付款能力受财政拨付限制
- **政府信用背书的不确定性**：政府不承担担保责任
- **非标融资风险**：信托、融资租赁等非标债务违约可能导致连锁追偿
- **债券借新还旧限制**：如果只能借新还旧，说明融资能力受限

## 路径可行性实测与成功率矩阵 ★v2.1

以下为经过实际测试的搜索路径可行性评级。**A级 = 高成功率（实测可获取有效数据）**；**B级 = 中成功率（可通过间接渠道获取部分数据）**；**C级 = 低成功率（信息不公开或反爬严重）**；**X级 = 不可行**。

### 实测结果总表

| 财产类型 | 搜索渠道 | 实测结果 | 成功率 | 典型输出 |
|---------|---------|---------|--------|---------|
| **工商信息**（注册资本/股东/法人） | WebSearch → 启信宝/天眼查/企查查缓存 | ✅ 成功 | **A** | 注册资本¥1.12亿、实缴¥0.2亿、股东结构、法人变更记录 |
| **土地划拨/出让记录** | WebSearch → **landchina.mnr.gov.cn**（自然资源部土地市场网） | ✅ 成功 | **A** | 地块位置、面积、用途、划拨日期——**这是查找平台公司土地的最高效渠道** |
| **建设项目清单** | WebSearch → 招标网/建设通/招采通 | ✅ 成功 | **A** | 项目名称、投资额、地块信息——可与土地记录交叉验证 |
| **债券信息/财务数据** | WebSearch → 中国货币网/上清所孔雀开屏 | ✅ 成功（如公司发行过债券） | **A** | 募集说明书含完整财务报表——**最权威的财务数据来源** |
| **区域财政/化债政策** | WebSearch → 债券信评报告/政府工作报告/新闻 | ✅ 成功 | **A** | 财政收入、债务率、化债进展——对评估区域偿付环境至关重要 |
| **间接涉诉信息** | WebSearch → 天眼查/企查查等第三方聚合 | ⚠️ 部分成功 | **B** | 可获取涉诉数量，但具体案情需进一步搜索裁判文书网 |
| **裁判文书** | WebSearch → wenshu.court.gov.cn 或第三方转载 | ⚠️ 部分成功 | **B** | 部分判决书可搜到全文，但反爬措施导致覆盖不完整 |

| **应收账款明细** | WebSearch → 债券募集说明书（如有） | ⚠️ 仅平台公司发行过债券时可用 | **B** | 募集说明书披露前五大应收款对象 |

| **完整不动产登记** | — | ❌ 需律师持调查令到不动产登记中心 | **X** | 土地划拨公示是唯一公开渠道，完整清单需法院调查令 |
| **车辆登记** | — | ❌ 不公开 | **X** | 需法院调查令向车管所查询 |

### 黄金渠道详解

#### 渠道1：landchina.mnr.gov.cn（自然资源部土地市场网）★★★

**适用范围**：查找政府平台公司通过划拨/出让方式获取的所有土地

**搜索方法**：
```
WebSearch "公司全名 site:landchina.mnr.gov.cn"
或 WebSearch "公司全名 国有土地划拨"
或 WebSearch "公司全名 土地 批前公示"
```

**实测效果**：可查到该公司名下的完整土地清单（2020-2024年至少10宗教育用地），包括：
- 合同签订日期
- 土地面积（精确到㎡）
- 地块位置
- 土地用途
- 供地方式（划拨/出让）

#### 渠道2：中国货币网/上清所（债券信息披露）★★★

**适用范围**：适用于发行过债券的平台公司

**搜索方法**：
```
WebSearch "公司全名 募集说明书"
或 WebSearch "公司全名 中期票据"
或 WebSearch "公司全名 财务报告"
```

**实测效果**：可获取募集说明书中的完整财务数据，包括：
- 资产负债表（总资产、负债、净资产）
- 利润表（营业收入、净利润、政府补贴）
- 现金流量表
- 前五大客户/供应商
- 风险揭示章节

#### 渠道3：招标网/建设通/招采通（项目信息）★★★

**适用范围**：查找平台公司投资建设的所有项目

**搜索方法**：
```
WebSearch "公司全名 项目" OR "公司全名 招标"
WebSearch "公司全名 建设" OR "公司全名 施工"
```

### 渠道降级策略

当A级渠道无法获取足够信息时，启动以下降级方案：

```
第一层：WebSearch 公开数据（A/B级渠道）
    ↓ 如数据不足
第二层：WebFetch 精确抓取（对 Search 找到的高价值URL进行深度抓取）
    ↓ 如仍不足
第三层：标注 [需律师核查] + 生成调查令申请草案
    - 列出需要通过律师调查令获取的信息清单
    - 给出调查令的申请对象（不动产登记中心/银行/车管所/工商局）
```

### 调查令申请指引

以下财产信息的完整数据需要通过执业律师持法院签发的调查令获取，Agent 应生成调查令申请要点：
