# OCR证据核验协议

## 概述

本文件定义在建设工程合同分析中，对通过 MinerU OCR / pdfplumber 扫描件提取的文字内容进行核验的强制性协议。OCR提取的高风险结论必须在原件核实前标注不确定性。

### 核验层级 ★v2.1

核验分为三个层级，按优先级递进：

```
Level 1: MinerU OCR → 主力文字提取
    ↓ 发现高风险信号
Level 2: Agnes AI Vision → AI视觉核验（印章识别、批注判断、OCR交叉验证）
    ↓ 仍存疑
Level 3: 原件肉眼核实 → 调取原件比对
```

**Agnes AI Vision（Level 2）的优势**：
- 能区分印章内容与文档内容（MinerU 可能将印章文字误读为文档内容）
- 能识别印章格式文字（"签字盖章有效，否则无效"）vs 实质性标记（"合同无效"）
- 能基于上下文判断标记的性质，而非孤立字符识别

## 适用范围

以下场景 **强制适用** 本协议：

1. 通过 MinerU API 对扫描型PDF进行OCR提取
2. 通过 pdfplumber 对文字型PDF进行文本提取（但内容涉及CID编码/乱码/异常字符）
3. 任何基于上述提取结果做出的、具有法律效力的分析结论

## 分级核验标准

### Level 1：可直接采用（无需原件核实）

**适用条件**（全部满足）：
- 提取的文字清晰、连续、无乱码
- 内容为常规事实陈述（如合同条款、日期、金额等已在其他文件中交叉验证的信息）
- 对应结论的风险等级为"常规"

**标注方式**：无需特殊标注

### Level 2：可采用但需标注（建议原件核实）

**适用条件**（任一满足）：
- 提取的文字有小范围模糊或不确定（如个别字符不清晰但可合理推断）
- 内容为对法律分析有影响但非决定性的事实
- 对应结论的风险等级为"优先"

**标注方式**：`[OCR提取·建议原件比对]`

### Level 3：禁止直接采用（强制原件核实）

**适用条件**（任一满足）：
- 提取的文字模糊、存在多种解读可能（如"合同无效"vs"合格有效"）
- 内容构成严重或致命风险结论的**唯一证据基础**
- 对应结论的风险等级为"严重"
- 该事实在法律分析中起决定性作用

**标注方式**：`[OCR提取·需原件核实]`，且结论必须表述为"如OCR提取无误，则……"，不得表述为确定性结论

## 高风险OCR信号识别

以下字符/模式在OCR输出中出现时，**自动触发 Level 3**：

| OCR输出 | 可能的含义 | 风险 |
|---------|----------|------|
| "合元效" | "合同无效" | **致命** |
| "合周元效" | "合同无效" | **致命** |
| "合免" / "合免无效" | "合同无效" | **致命** |
| 金额数字与明确约定差额>20% | 可能为OCR识别错误 | **严重** |
| 日期与其他文件交叉矛盾 | 可能为OCR识别错误 | **严重** |
| 签名/印章区域无识别结果 | 可能遗漏关键签章信息 | **优先** |

## 核验执行流程

```
OCR提取事实发现
    ↓
评估该事实的风险影响等级
    ↓
├── 常规 → Level 1 → 直接采用
├── 优先 → Level 2 → 标注 [OCR提取·建议原件比对]
└── 严重/致命 → Level 3 → 标注 [OCR提取·需原件核实]
                            ↓
                      结论表述为条件句："如OCR提取无误，则……"
                            ↓
                      在行动建议中增加 P0："调取原件肉眼核实"
```

## 在文书中的呈现格式

```markdown
### X.X [事项分析]

**OCR核验状态**：[Level 1/2/3] [说明]

**OCR提取内容**：
> "[OCR提取的原文]" [OCR提取·需原件核实]

**基于OCR的分析**（Level 3 示例）：
如上述OCR提取内容在原件中确认无误，则[条件性分析结论]。但在原件核实前，本分析结论具有不确定性，不应作为决策的唯一依据。
```

## 与 construction-legal-writing 的集成

- `construction-legal-writing` 的 **R2 事实陈述审核** 和 **R7 内部一致性审核** 会交叉检查OCR标注
- `construction-legal-writing` 的 **规则0-1** 与本协议完全对应
- 法律意见书在每次引用OCR事实时，必须符合本协议的分级标注要求
