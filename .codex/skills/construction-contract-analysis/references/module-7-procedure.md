# 模块七：程序与执行

## 触发条件

用户提到：管辖、诉讼、仲裁、合同效力、无效合同、司法鉴定、执行、优先受偿权、查封、冻结、诉讼时效

## 管辖规则

### 专属管辖

建设工程施工合同纠纷由**工程所在地**人民法院专属管辖，当事人的约定管辖不得违反。

### 仲裁

- 有效仲裁协议排除法院管辖
- 仲裁协议独立性：合同无效不影响仲裁条款效力
- 约定不明（如"提交仲裁机构或法院"）→ 仲裁协议无效

## 合同效力判断

### 五种无效情形速查

1. 无资质 / 超越资质等级
2. 挂靠（借用资质）
3. 应招标未招标 / 中标无效
4. 转包
5. 违法分包

### 无效后果

- 验收合格 → 参照合同折价补偿
- 验收不合格 → 修复后合格的，修复费承包人承担；仍不合格的，无权请求补偿
- 发包人过错的 → 承担相应责任

## 司法鉴定

### 何时申请

- 双方对已完工程量争议大
- 双方对工程造价争议大
- 质量问题的原因和修复费用需要专业技术判断
- 工期延误原因和责任需要专业分析

### 策略要点

- 尽早申请，避免程序拖延
- 明确鉴定范围和事项（不能笼统说"对工程造价进行鉴定"）
- 对鉴定意见的异议要有理有据

## 建设工程价款优先受偿权

### 核心规则

- **期限**：发包人应付款之日起 **18 个月**内行使
- **范围**：工程价款（含人员报酬、材料款等实际支出），不含利息、违约金、损害赔偿
- **效力**：优先于抵押权和其他债权
- **放弃**：损害建筑工人利益的放弃无效

## 执行程序

### 执行要点

- 首先查发包人名下不动产（在建工程/已竣工房屋）
- 申请对在建工程的查封和价值评估
- 优先受偿权的执行需在法定期限内提出
- 发包人破产时及时申报债权并主张优先权

## 输出要求

- 管辖分析结论
- 合同效力评估
- 鉴定申请建议（是否需要/时机/范围）
- 优先受偿权行使期限提醒
- 执行策略建议


## 黑白合同

### 认定标准

黑白合同（也称"阴阳合同"）是指招标人与中标人另行签订的合同与中标合同在实质性内容上不一致。

**实质性内容**包括：工程范围、建设工期、工程质量、工程价款等核心条款。

| 黑合同情形 | 认定结果 |
|-----------|---------|
| 中标前实质性谈判（先签后招） | 黑合同无效，阳合同有效 |
| 中标后另行签订让利/压价协议 | 以阳合同为结算依据 |
| 备案合同与实际履行合同不一致 | 以备案的阳合同为准（有例外） |
| 中标合同无效但实际履行了黑合同 | 参照实际履行的合同折价补偿 |

### 结算规则

- 阳合同有效、黑合同无效 → 按阳合同结算
- 阳合同无效、黑合同也无效 → 参照实际履行的合同结算
- 无法确定实际履行哪份 → 参照最后签订的合同结算
- 多份合同均无效且无法确定实际履行 → 按定额标准结算

### 最新动态

2025年司法解释（二）征求意见稿：中标前实质性谈判、先签合同后招标等违反招标投标法的，阴阳合同均可能无效。 [征求意见稿] [未生效]

### 2025征求意见稿对黑白合同的新规则 ★2025更新

| 新规则 | 内容 | 影响 |
|--------|------|------|
| 虚假意思表示 | "白合同"（中标备案合同）属虚假意思表示，无效；"黑合同"（实际履行合同）若本身不违反强制性规定，有效 | 颠覆传统黑白合同认知 |
| 先定后招 | 标前就实质性内容谈判且参与谈判者中标的，黑白合同均无效 | 严格规制招标程序 |
| 招标项目性质变化 | 起诉时项目已不再属必须招标范围的，不应以未招标为由认定合同无效 | 引入"情势变更"考量，避免政策调整导致合同效力被轻易否定 [征求意见稿] [未生效] |


## 实际施工人制度

### 定义

实际施工人是指转包、违法分包、挂靠等无效合同情形下实际完成工程施工的单位或个人。区别于合法施工合同的承包人。

### 核心权利

#### 突破合同相对性

实际施工人可以向发包人主张工程款（发包人在欠付总包范围内承担责任），前提是存在转包或违法分包（不含挂靠）。

```
实际施工人 → 发包人（突破合同相对性）
    ↑             ↓
转包人/违法分包人 在欠付范围内承担责任
```

#### 代位权

实际施工人可以行使代位权，以自己的名义代位行使转包人/违法分包人对发包人的债权。

### 限制与变化

- 2025年征求意见稿：实际施工人原则上只能向合同相对方主张，突破合同相对性受到限制
- 代位权路径优先：实际施工人应先主张代位权
- 农民工工资特殊保护：农民工可直接向发包人、总包单位主张工资（不论是否存在转包）
- **2025征求意见稿重大变化** ★：
  - 多层转包/违法分包中的实际施工人不得直接起诉发包人 [征求意见稿] [未生效]
  - 发包人**知道或应当知道**挂靠的，实际施工人可直接向发包人主张权利 [征求意见稿] [未生效]
  - 发包人**不知道**挂靠的，实际施工人不得直接向发包人主张，仅可向被挂靠人主张 [征求意见稿] [未生效]

### 挂靠人处理

挂靠人（借用资质）不适用实际施工人突破合同相对性的规则，只能向被挂靠人主张。

### 证据要点

- 证明实际施工身份：材料采购合同/付款凭证、工人考勤/工资发放记录、现场签证单签字
- 证明发包人欠付：对账单、结算文件、催款函


## 合同效力深化：挂靠责任分配

### 挂靠人（借用资质）与转包的区别

| 区分点 | 挂靠 | 转包 |
|--------|------|------|
| 名义主体 | 挂靠人以被挂靠人名义施工 | 转包人以自己名义施工 |
| 管理关系 | 被挂靠人收取管理费，不实际管理 | 转包人完全退出 |
| 发包人知情 | 发包人可能知道也可能不知道 | 发包人通常不知情 |

### 挂靠的责任分配

| 情形 | 发包人责任 | 被挂靠人责任 | 挂靠人权利 |
|------|-----------|-------------|-----------|
| 发包人不知道挂靠 | 在欠付工程款范围内承担责任 | 对工程质量承担连带责任 | 可向被挂靠人主张；不能向发包人主张（2025新规） |
| 发包人知道或应知挂靠 | 与挂靠人形成事实合同关系，应直接付款 | 同上 | 可向发包人直接主张 |
| 工程质量不合格 | 发包人可按合同约定主张维修费用 | 与挂靠人承担连带赔偿责任 | 须修复合格后方可主张工程款 |

**★ 2025征求意见稿新增：挂靠管理费规则** [征求意见稿] [未生效]：
- 出借资质合同无效，**管理费不受法律保护**——被挂靠人收取的管理费应予返还或不予支持
- 借用资质方施工合格的，可获折价补偿（依据《民法典》第157条）
- 挂靠人以出借企业名义对外采购、借款，符合表见代理的，出借企业承担民事责任 [征求意见稿] [未生效]

### 内部承包 vs 挂靠/转包

合法的内部承包应同时满足以下要件：
1. 承包人是企业正式在编员工（有社保/劳动合同）
2. 企业对项目进行实质管理（技术/安全/质量/财务）
3. 项目盈亏由企业最终承担

缺少以上任一项，可能被认定为挂靠或转包。


## 固定总价合同突破鉴定

### 核心问题

固定总价合同在诉讼/仲裁中，一方能否申请对工程造价进行鉴定？

### 规则

| 情形 | 能否鉴定 | 原因 |
|------|---------|------|
| 合同内项目全部完成 | 不能（除非合同无效） | 固定总价已锁定 |
| 合同内项目部分未完成（未完工程）| 可以鉴定，但仅对未完部分 | 需确定未完部分的扣减额 |
| 合同外新增项目 | 可以鉴定 | 合同外项目不受固定总价约束 |
| 材料价格异常波动 | 一般不鉴定，通过情势变更调整 | 固定总价包含价格风险 |
| 合同无效 | 可以鉴定（参照合同约定折价补偿时需确定已完工程价值）| |

### 鉴定方法选择

| 方法 | 适用 | 说明 |
|------|------|------|
| 定额比例法 | 未完工程 | 已完/全部定额造价比例 × 固定总价 |
| 合同内+合同外分开 | 有合同外项目 | 固定总价部分不动+合同外部分单独鉴定 |
| 整体重置法 | 合同无效 | 重新按定额计算已完工程造价，参照合同约定的下浮率 |

### 裁判倾向

- 固定总价合同的鉴定申请一般不获支持，法院倾向于维护固定总价的约束力
- 但未完工程、合同外项目、合同无效三种情形存在突破空间
- 申请人应明确提出"合同无效"或"未完工程"作为鉴定申请的请求权基础


## 放弃优先受偿权的效力

### 基本规则

| 放弃情形 | 效力 | 理由 |
|---------|------|------|
| 明确放弃优先权（不涉第三人利益）| 有效 | 处分自身权利 |
| 放弃损害建筑工人工资部分 | 无效 | 损害第三人利益，违反公序良俗 |
| 以放弃优先权为条件获得贷款（银行要求）| 效力待定 | 需分析是否损害工人利益 |
| 约定放弃但实际未办理不动产登记 | 放弃可能不生效 | 优先权属法定担保物权 |

### 有效放弃的条件

1. 放弃意思表示真实、明确
2. 不损害建筑工人利益（须有证据证明已足额支付工人工资）
3. 不涉及虚假破产/恶意逃债

### 无效放弃的后果

放弃优先权的部分无效，不影响整体放弃的效力——即放弃行为整体无效，承包人仍享有优先权。


## 无效合同折价补偿细化规则

### 参照合同约定的范围

合同无效但工程质量合格的，承包人可以请求参照合同约定折价补偿。涉及以下要素的细化规则：

| 要素 | 是否参照 | 裁判倾向 |
|------|---------|---------|
| 固定总价 | 参照 | 按约定总价计算 |
| 计价方式（总价/单价）| 参照 | 按约定计价方式结算 |
| 付款时间 | 参照 | 按约定时间起算利息 |
| 下浮率/让利率 | 参照 | 下浮率同样适用（双方意思真实） |
| 违约金条款 | 不参照 | 无效合同无违约金 |
| 逾期付款利息标准 | 一般不参照 | 按法定LPR计算 |
| 质保金条款 | 参照 | 按约定扣留和返还 |

### 损失分担

合同无效后的损失（停工/窝工/材料浪费等），按双方过错比例分担。

| 过错类型 | 责任比例倾向 |
|---------|-------------|
| 发包人应招标未招标 | 发包人承担主要责任（60-70%） |
| 承包人无资质/超越资质 | 承包人承担主要责任（60-70%） |
| 双方均有过错 | 按过错程度分担（常见各50%） |
| 发包人知道挂靠仍发包 | 发包人承担主要责任 |

### 利润问题

合同无效时，承包人是否可以主张利润？
- 主流裁判规则：折价补偿包含合理利润（已完工程的实际价值含利润）
- 少部分裁判观点：利润不属于"实际支出"，不予支持
- 建议：在需求确认阶段向用户说明此风险 [需审查]


## 2025年司法解释二（征求意见稿）新增规则 ★

> 以下规则来源于最高人民法院2025年11月发布的《关于审理建设工程施工合同纠纷案件适用法律问题的解释（二）（征求意见稿）》，正式稿尚未颁布。所有引用标注 `[征求意见稿]` `[未生效]`，仅供趋势参考，不构成确定的法律依据。

### 结算协议独立性

**规则**：施工合同无效，不影响双方事后达成的结算协议的效力。 [征求意见稿] [未生效]

**实务影响**：
- 即使施工合同因挂靠/转包/未招标等原因无效，双方事后签署的结算协议仍可作为价款依据
- 结算协议需满足：双方真实意思表示 + 不违反强制性规定 + 内容具体明确
- 一方以"合同无效故结算协议也无效"为由反悔的，法院不予支持

### 质保金返还起算时点

**规则**：合同解除或无效时，质保金返还的缺陷责任期从**承包人退场之日**或判决生效之日起算。 [征求意见稿] [未生效]

**实务影响**：
- 合同中途解约时，质保金起算点不再是竣工验收日，而是退场日
- 承包人应及时记录退场日期并保留交接记录

### EPC合同/劳务分包合同专属管辖

**规则**：EPC总承包合同纠纷由工程所在地法院**专属管辖**，适用建设工程合同相关解释。劳务分包合同纠纷同样由工程所在地法院专属管辖。 [征求意见稿] [未生效]

**实务影响**：
- EPC合同不能以"含有设计/采购"为由排除专属管辖
- 劳务分包合同统一适用工程所在地管辖

### 移送行政主管部门

**规则**：法院在审理建设工程合同纠纷中发现出借资质、转包、违法分包等严重违法情形的，应**移送行政主管部门**处理。 [征求意见稿] [未生效]

**实务影响**：
- 诉讼不再是"纯民事"程序——违法行为可能触发行政调查
- 应告知当事人诉讼中暴露违法行为的行政风险

### 固定总价合同与情势变更

**规则**：固定总价合同原则上不调价，仅**情势变更**（《民法典》第533条）标准下可调整。 [征求意见稿] [未生效]

### 审计/财政评审条款

**规则**：合同未约定以审计结论为结算依据的，不得以审计为结算依据。非承包人原因导致审计长期未出结论的，可申请司法鉴定。 [征求意见稿] [未生效]
