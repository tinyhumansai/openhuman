# 多项目边界澄清

## 概述

当合同中涉及多个关联项目（如"第五高级中学及第六学校"），或财务数据跨越多个项目，分析时必须明确各项目的法律和财务边界。本模块定义边界澄清的强制要求。

## 触发条件

以下任一情形出现，**强制触发**本模块：

| 条件 | 示例 |
|------|------|
| 合同文件中同时提及两个或以上独立项目 | EPC合同含五高和六校两所学校 |
| 收款明细/造价数据跨越多个项目 | 收款台账中五高和六校混合排列 |
| 关联诉讼同时涉及多项目 | 钢结构鉴定覆盖五高+六校 |
| 代建协议将原项目拆分为多个子项目 | 补充协议将十九所学校调整为二十所 |

## 强制澄清事项

### 1. 财务边界

对于跨项目的财务数据，必须输出：

```markdown
| 项目 | 合同价 | 甲批量 | 已收款 | 欠付金额 |
|------|--------|--------|--------|---------|
| 五高 | ¥XX | ¥XX | ¥XX | ¥XX |
| 六校 | ¥XX | ¥XX | ¥XX | ¥XX |
| 合计 | ¥XX | ¥XX | ¥XX | ¥XX |
```

如果某些数据无法拆分（如钢结构鉴定总价¥187,819,751.50同时覆盖五高和六校），必须说明：
- 拆分依据（鉴定报告中是否有每个子项的单独金额）
- 如无法拆分，标注"需单独查明"并评估对诉讼策略的影响

### 2. 合同关系边界

对于代建/拆分/合并的项目，必须明确：
- 每所学校是否有独立的EPC合同，还是多所学校共用一份总合同
- 代建协议拆分为"五高+六校"后，原EPC合同的约束力是否延伸到拆分后的两个学校
- 不同学校的发包方、代建人、监理方是否一致

### 3. 诉讼策略边界

对于跨项目的追索，必须评估：
- 是否应将五高和六校的债权合并起诉（共享合同+共享发包方）还是分开处理
- 合并起诉的优势（一次性解决、降低成本）和劣势（案情复杂化、单项目抗辩混同）
- 分开起诉的优势（聚焦单一争议）和劣势（重复诉讼成本、既判力冲突风险）

### 4. 关联判决的边界

如关联判决同时涉及多项目，必须分析：
- 判决中对五高和六校各自的金额认定是否清晰可拆分
- 如不可拆分，在向发包方主张时如何处理

## 禁止行为

| 禁止 | 原因 |
|------|------|
| ❌ 在多项目数据中仅分析一个项目而不说明 | 遗漏潜在债权或被告 |
| ❌ 在多项目数据混合时默认按比例拆分 | 拆分依据需要明确证据支撑 |
| ❌ 在多项目背景下不评估合并/分开起诉的策略 | 影响案件处理效率和既判力 |
