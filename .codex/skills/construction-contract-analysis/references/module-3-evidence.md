# 模块三：证据梳理与固定

## 触发条件

用户提到：证据、举证、证据目录、质证、原件、复印件、证据链、往来函件、施工日志、验收记录、付款凭证

## 五大证据分类体系

### 1. 合同类证据

| 子类 | 典型材料 | 证明目的 |
|------|---------|---------|
| 主合同 | 总包/分包施工合同 | 权利义务基础 |
| 补充文件 | 补充协议、承诺书、会议纪要 | 合同变更和补充约定 |
| 结算文件 | 对账协议、结算确认书 | 款项确认 |
| 过程文件 | 往来函件、催告通知、签收记录 | 通知和催告事实 |

### 2. 施工履约证据

| 子类 | 典型材料 | 证明目的 |
|------|---------|---------|
| 开工文件 | 开工令/开工报告/施工许可证 | 开工日期 |
| 过程记录 | 施工日志、监理日志 | 施工过程事实 |
| 验收文件 | 隐蔽工程验收、分部分项验收、竣工验收 | 质量合格 |
| 变更文件 | 签证单、洽商记录、变更通知 | 工程变更事实 |
| 通知催告 | 各类通知函、催告函及签收记录 | 通知送达 |

### 3. 款项证据

| 子类 | 典型材料 | 证明目的 |
|------|---------|---------|
| 付款凭证 | 银行转账凭证、支票/汇票存根 | 付款事实和金额 |
| 发票/收据 | 增值税发票、收据 | 款项对应关系 |
| 报审资料 | 进度款报审表、结算报审书 | 承包人主张的金额 |
| 扣款单 | 甲供材扣款通知、罚款通知 | 扣款的合法依据 |

### 4. 工期证据

| 子类 | 典型材料 | 证明目的 |
|------|---------|---------|
| 延误证据 | 停工通知、复工通知、延误报告 | 延误事实和原因 |
| 顺延证据 | 工期顺延申请及审批 | 合理顺延 |
| 外部证据 | 天气记录、政策文件、第三方证明 | 不可抗力/外部原因 |
| 进度证据 | 施工进度计划、实际进度对比 | 工期偏差程度 |

### 5. 质量证据

| 子类 | 典型材料 | 证明目的 |
|------|---------|---------|
| 验收证据 | 分部/分项验收报告、检测报告 | 质量合格/不合格 |
| 整改证据 | 整改通知、整改报告、复查记录 | 缺陷通知和修复 |
| 保修证据 | 维修通知、维修记录 | 保修期内的修复 |
| 擅自使用 | 未经竣工验收擅自使用的证据 | 转移质量责任 |

## 证据组织原则

1. **原件优先**：原件 > 核对无误的复印件 > 无原件的复印件
2. **形成证据链**：单一证据证明力有限，应组织关联证据构成完整链条
3. **按争议焦点组织**：不按时间线、不按文件类型，而是按争议焦点归类
4. **来源标签**：每份证据标注来源（由谁提供/从何处获得）
5. **OCR证据标注** ★v2.0：通过OCR提取的证据必须标注 `[OCR]` + 核验等级，高风险结论需标注"需原件核对"。详见 `ocr-verification-protocol.md`
6. **模板文本标注** ★v2.0：依据招标文件模板（非实际签署版本）的证据标注 `[模板]`
7. **缺失证据列表** ★v2.0：列出应收集但目前缺位的关键证据，标注取证建议

## 电子数据证据施工专项指引 ★v2.1新增

### 电子证据类型与认定

| 电子证据类型 | 典型场景 | 审查要点 | 法律依据 |
|-------------|---------|---------|---------|
| 微信/钉钉聊天记录 | 工程指令、变更确认、催告通知 | 实名认证+完整记录+公证/时间戳 | 证据规定第93-94条 |
| 电子邮件 | 工程往来函件、设计变更、结算沟通 | 邮箱归属+发件人权限+邮件完整性 | 证据规定第93条 |
| 电子签章文件 | 电子合同、电子签证单 | 电子认证服务机构的资质+签章有效性 | 《电子签名法》第13-14条 |
| OA/项目管理平台 | 审批记录、BIM平台数据 | 平台运营方中立性+数据不可篡改性 | 证据规定第94条 |
| 手机照片/视频 | 施工现场记录、质量问题、验收过程 | 拍摄时间+地点定位+未编辑（原始文件） | 证据规定第90条 |

### 微信/钉钉工程指令的证明力

**认定规则**：
1. **发送方身份确认**：需结合头像、微信号/手机号、实名认证信息、历史交互记录
2. **内容完整性**：需包含前后文（不能仅截取单条消息），标注发送时间、发送状态
3. **实质内容判断**：是否构成工程指令、变更确认、催告通知，需从内容客观分析

**证据固定方式**（按效力从高到低）：
- 公证机关保全公证（最高效力）
- 可信时间戳存证（联合信任时间戳服务中心等）
- 手机截图 + 当庭演示（效力较低但可接受）
- 打印件（仅作初步证据，需当庭演示或原件核对）

**常见陷阱**：
- 头像/昵称可变更 → 需结合其他证据确定发件人身份
- 消息可撤回/删除 → 收到重要指令后应及时公证存证
- "嗯""收到""好的"是否构成确认 → 法院对此态度谨慎，需结合上下文判断
- 仅截取对自己有利的单句 → 可能被对方提交完整记录后反驳，损害诚信

### 电子邮件的证据保全

```
电子邮件证据链构建：
1. 邮件客户端完整截图（含发件人、收件人、时间、主题、正文）
2. 附件单独保存并在证据清单中对应列出
3. 可要求邮件服务提供商出具邮件记录证明
4. 重大事项建议面签+邮件确认双重锁定
```


## 证据链构建方法论 ★v2.1新增

### 从单一证据到完整证据链

诉讼中，单一证据的证明力有限。证据链的核心逻辑：

```
单一证据（点）
    ↓ + 关联证据
证据组（线）—— 如"合同+签证+验收"形成变更事实线
    ↓ + 交叉验证
证据链（面）—— 如"变更事实线+付款事实线+工期事实线"形成完整事件
    ↓ + 排除合理解释
达到高度盖然性证明标准
```

### "书证+书证+第三方"三角验证

| 验证关系 | 示例 |
|---------|------|
| 书证 ← → 书证 | 施工合同（权利义务）+ 签证单（变更事实）+ 付款凭证（付款事实）= 变更索赔完整链条 |
| 书证 ← → 第三方记录 | 停工通知（发包人盖章）+ 监理日志（监理独立记录）+ 现场照片（客观状态）= 停工事实成立 |
| 书证 ← → 电子数据 | 合同约定 + 微信指令截屏（发包人负责人）+ 钉钉审批记录 = 口头变更获书面追认 |

### 常见证据链构建示例

#### 1. 工期延误索赔证据链
```
开工令/开工报告 → 原始施工进度计划 → 停工通知（发包人签发）
→ 停工期间施工日志（记录停工状态及现场人数/机械）
→ 复工令 → 实际竣工报告 → 计划vs实际工期对比表
```

#### 2. 增量价款索赔证据链
```
合同计价条款 → 设计变更通知（发包人签发）
→ 现场签证单（双方签认，含工程量+单价）
→ 增量价款计算书 → 发包人审批/默示认可记录
```

#### 3. 质量瑕疵扣款抗辩证据链
```
质量验收标准（合同约定）→ 验收记录（显示具体瑕疵位置和程度）
→ 整改通知（书面通知承包人修复+签收记录）
→ 承包人逾期未修复或不修复的再次催告记录
→ 第三方修复合同+付款凭证 → 修复前后对比照片
```


## 常见证据缺失场景与补救方案 ★v2.1新增

### 场景一：口头变更/口头指令无书面确认

**问题**：现场口头指令（"把这个改了""再加一层"）事后未签签证单。

**补救方案**（按优先级）：
1. **事后追认函**：起草书面确认函，请发包人/监理签认"已于X月X日口头指令XX变更，现书面补确认"
2. **会议纪要引用**：在后续会议纪要中写入"关于上次会议确定的口头指令XX，截至X月X日已完成..."
3. **施工记录固定**：在施工日志/监理日志中详细记录口头指令的时间、地点、内容、发出人
4. **照片+视频**：指令施工前后的现场对比（需+时间标识+定位）
5. **微信/钉钉追认**：发送消息请对方确认"X总，上次您现场说的XX变更，我们按您要求做了，您确认一下"

### 场景二：隐蔽工程无验收记录

**问题**：隐蔽工程已经覆盖，事后无法现场查验。

**补救方案**：
1. 挖掘隐蔽工程覆盖前的**影像资料**（施工过程中的照片/视频）
2. 收集**材料进场验收记录**（证明材料已通过甲方验收）
3. 收集**监理旁站记录**（证明施工过程有监理在场监督）
4. 申请**局部开挖检测**（如争议金额足够大、技术上可行）
5. **证人证言**（现场施工人员/监理人员出庭作证）

### 场景三：甲供材质量问题未书面提出

**问题**：发包人供应的材料有缺陷，但承包人未及时书面提出异议。

**补救方案**：
1. 收集**材料进场时的外观检查记录**（照片/视频/入库记录）
2. 收集使用后**出现问题的时间记录**（现场照片/检测报告）
3. **已尽通知义务的碎片证据**（短信/微信/电话记录截图——即使不完整也有价值）
4. 申请对**剩余未使用的同批甲供材**进行质量检测
5. 法律依据：《民法典》第775条——承揽人应及时检验，发现不符应及时通知 `[法条原文]`

### 场景四：停窝工损失的人员/机械数据无法核实

**问题**：停工期间施工日志不全，无法精确证明每日窝工人数和停滞机械数。

**补救方案**：
1. 收集停工**前后的**考勤记录/工资表（证明停工前在岗人数，推算停工期间的合理人数）
2. 收集**进退场记录**（证明工人/机械在停工期间确实留在现场）
3. 收集停工期间**有限的管理记录**（安全巡检记录、材料看管记录、保安日志）
4. 收集**第三方记录**（保安公司出勤记录、材料供应商送货单上的签收人）
5. 申请对监理和发包人**现场代表调查取证**
