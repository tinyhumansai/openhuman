# 模块一：合同条款摘录与法律实务分析

## 触发条件

用户提到：条款、合同条款、审查合同、约定内容、合同约定、造价模式、质量标准、工期约定、违约责任、调价、不可抗力、管辖、质保、进度款条件、变更签证、转包分包、合同解除、送达默示

## 分析框架

对每一条款执行**四维分析**，**强制要求原文引用**：

```
原文摘录(必填) → 风险识别 → 裁判影响 → 争议研判
```

**分析输出强制格式**：

```markdown
#### CX. XXX条款

**原文摘录**：
> [从合同中直接引用该条款的原文，不可仅用概括性描述。保持合同原有表述，包括数字、百分比、
> 专业术语、时间节点等关键信息。多条款项分开摘录，每段标注所属页码。]

**风险识别**：[基于原文的具体风险分析]
**裁判影响**：[司法实践中该类条款的处理倾向]
**争议研判**：[可能引发的争议及应对策略]
```

**重要**：没有原文摘录的条款分析视为不完整。分析结论必须有原文作为依据，杜绝凭印象研判。

---

### C1. 造价模式条款

**摘录要点**：
- 计价方式（固定总价/固定单价/可调价/成本加酬金）的原文表述
- 承包范围对应的计价口径
- 包干范围（含/不含内容）
- 暂列金/暂估价处理方式
- 风险范围（材料价格波动风险由谁承担）

**风险点**：
- 固定总价包干范围不清晰 → 施工中增量结算争议
- 图纸包干 vs 清单包干边界模糊 → 量差争议
- 未约定材料涨价风险分担 → 合同履行僵局

**裁判规则**：
- 固定价合同一般不支持材料涨价调价请求（司法实践主流观点）
- 但异常波动超出商业风险的可情势变更（民法典第 533 条）
- 清单漏项/量差在合理范围内的由承包人承担

---

### C2. 工程质量条款

**摘录要点**：
- 质量标准（国标/行标/甲方特殊标准）
- 隐蔽工程验收流程和时间节点
- 分部分项验收/竣工验收标准
- 质量不合格整改期限
- 未验收擅自使用的责任条款

**风险点**：
- 甲方特殊标准过高 → 变相增加成本
- 隐蔽工程验收流程过长 → 工期延误
- 未约定质量问题的扣款标准 → 付款抗辩缺乏依据

**裁判规则**：
- 发包人未经验收擅自使用 → 视为质量合格（但地基基础和主体结构除外）
- 质量瑕疵可抵扣但需举证瑕疵事实和修复费用

---

### C3. 工期条款

**摘录要点**：
- 开工/竣工日期的具体约定
- 总工期/节点工期的日历天数
- 工期顺延条件（甲方原因/不可抗力/政策变化等）
- 工期报审流程（顺延申请的提交时限）
- 停工/复工条件和流程

**风险点**：
- 开工日期定义模糊（实际开工 vs 合同约定开工 vs 开工令日期）
- 顺延条件过于严格（排除合理的工期顺延事由）
- 逾期申请视为放弃顺延的条款（默示条款效力争议）

**裁判规则**：
- 实际开工日期 > 合同约定日期 > 开工报告日期 > 施工许可证日期
- 甲方原因导致的工期顺延不要求承包人按期申报（即可豁免逾期申请失权）

---

### C4. 违约责任条款

**摘录要点**：
- 甲方逾期付款违约金标准（%/日或‰/日）
- 乙方逾期竣工违约金标准
- 质量违约/擅自转包分包的违约金
- 违约金上限约定
- 单方解约的违约责任

**风险点**：
- 违约金标准过高 → 可被法院调整
- 违约金标准过低 → 不足以约束对方
- 未约定违约金上限 → 违约责任可能无限扩大

**裁判规则**：
- 违约金超损失 30% 可申请减少（民法典第 585 条）
- 违约金过低可申请增加至实际损失水平

---

### C5. 价款调价条款

**摘录要点**：
- 材料涨跌调价的触发条件和幅度
- 人工费调价的政策依据
- 调价申报时限和审批流程
- 逾期未申报的后果

**风险点**：
- 调价申报时限过短 → 承包人易失权
- 风险包干幅度过大 → 承包人承担过度市场风险
- 未约定调价机制 → 固定价合同涨价风险完全由承包人承担

**裁判规则**：
- 固定总价合同原则上不调价，除非构成情势变更
- 政策性调整（如最低工资上调）可适用情势变更
- 逾期未申报是否失权取决于合同是否有明确约定

---

### C6. 不可抗力条款

**摘录要点**：
- 不可抗力范围（是否包含疫情/恶劣天气/政策变化等）
- 通知义务和举证时限
- 工期顺延规则
- 双方免责范围和损失承担

**风险点**：
- 不可抗力范围过窄 → 合理的延期事由不被认可
- 通知时限过短 → 失权风险
- 未约定损失分担 → 损失全由承包人承担

**裁判规则**：
- 疫情可认定为不可抗力（2020 年疫情后司法共识）
- 未履行通知义务 → 对扩大损失无权免责
- 恶劣天气需达到"不可预见、不能避免、不能克服"标准

---

### C7. 争议管辖条款

**摘录要点**：
- 约定管辖法院/仲裁机构的完整名称
- 管辖地（工程所在地/被告所在地等）
- 前置程序（协商/调解/专家裁定）

**风险点**：
- 约定管辖无效（违反专属管辖）
- 仲裁条款不明 → 仲裁协议无效
- 前置程序耗时过长 → 相等于限制诉权

**裁判规则**：
- 建设工程施工合同纠纷 → 专属管辖（工程所在地法院）
- 约定仲裁有效时可排除法院管辖
- 约定管辖违反专属管辖的 → 约定无效

---

### C8. 缺陷责任与质保条款

**摘录要点**：
- 缺陷责任期时长（通常 1-2 年）
- 质保期范围（地基基础/主体结构应为设计文件合理使用年限）
- 质保金比例（一般不超工程价款总额 3%）
- 质保金返还节点和逾期返还利息
- 缺陷修复责任

**风险点**：
- 混淆缺陷责任期和保修期 → 质保金返还节点争议
- 质保金比例过高 → 挤占承包人资金
- 未约定逾期返还利息 → 发包人拖延返还无成本

**裁判规则**：
- 缺陷责任期届满 → 发包人应返还质保金
- 保修期未届满不影响质保金返还
- 逾期返还质保金按同期 LPR 计息

---

### C9. 价款支付条款

**定义**：约定工程款支付的全流程安排——从预付款到质保金释放的支付节点、比例、方式、逾期利率，以及付款前置条件和各项扣款的协同机制。

---

#### 一、支付节点与比例（支付瀑布流）

**摘录要点**：
- **预付款**：金额/比例（通常合同价10%-30%）；支付条件（提交预付款保函/合同生效后X日内）；扣回方式（每期进度款等比例扣回/竣工一次扣回/不扣回）
- **进度款**：支付周期（按月/按节点/按季度）；支付比例（已完工程量的70%-85%）；最低支付限额（低于X万元并入下期）；计量周期和申报时限
- **竣工结算款**：结算完成后X日内支付至结算总价的95%-97%；尾款转为质保金
- **质保金释放**：缺陷责任期届满后X日内返还；分期返还的，各节点比例（通常第一年返50%-80%、第二年返剩余）

**风险点**：
- 预付款不提供保函 → 发包人承担承包人挪用风险
- 预付款扣回方式不明 → 扣回过快挤占承包人现金流
- 进度款支付比例过低 → 承包人长期垫资施工，现金流断裂风险
- 按月支付 vs 按节点支付 → 按节点支付对发包人有利（延迟付款），对承包人不利（资金周转）
- 竣工结算款支付期限过长（如"结算完成后180天"）→ 变相拖欠
- 质保金返还节点模糊 → 无限期扣押

**裁判规则**：
- 预付款未约定扣回的 → 视为工程款的一部分，不单独返还（除非合同明确约定为"借款"）
- 支付节点无约定 → 按司法解释一第27条确定起算时点（交付日/提交结算日/起诉日） `[法条原文]`
- 质保金返还节点无约定 → 缺陷责任期届满后返还（缺陷责任期无约定的，一般为2年）

---

#### 二、付款方式

**摘录要点**：
- 付款方式（银行转账/承兑汇票/供应链金融/信用证）
- 承兑汇票的贴息费用由谁承担
- 付款账户约定（是否接受第三方代付/委托付款）

**风险点**：
- **承兑汇票** → 实质相当于发包人延期付款6-12个月，承包人被迫承担贴现成本
- 承兑汇票未约定贴息承担方 → 承包人自行承担贴现损失
- 供应链金融（如"工付宝""建信融通"）→ 变相融资，发包人可能收取手续费
- 发包人用关联方账户付款 → 税务风险（三流不一致）

**裁判规则**：
- 合同约定"付款"但未明确方式的 → 一般理解为银行转账
- 发包人单方改用承兑汇票 → 构成违约，承包人可拒绝接受并要求按约付款
- 承兑汇票到期未兑付 → 承包人可同时主张票据权利和合同权利

**谈判策略**：
- 承包人：合同明确约定"以银行转账方式支付"，排除或严格限制承兑汇票
- 如无法排除承兑汇票：明确约定贴息费用由发包人承担、限定汇票期限（不超过6个月）、限定承兑汇票占比（不超过30%）

---

#### 三、逾期付款利率

**摘录要点**：
- 逾期付款利率约定（日万分之三/日万分之五/同期LPR的X倍）
- 利率是否包含违约金（逾期利率+违约金能否叠加计算）
- 无约定时的法定利率适用

**风险点**：
- 逾期利率约定过低 → 发包人拖欠成本低，缺乏付款压力
- 逾期利率约定过高 → 可能被法院调减（超过LPR四倍部分可能不被支持）
- 利率与违约金叠加 → 总量不得超出年化24%（部分法院观点）
- 无约定利率 → 只能按同期LPR主张，远低于商业融资成本

**裁判规则**：
- 有约定从约定（但不得过分高于实际损失——民法典第585条）`[法条原文]`
- 无约定 → 按同期LPR计算（司法解释一第26条）`[法条原文]`
- 2025示范文本趋势：逾期违约金LPR化，拖欠成本上升 `[征求意见稿]` `[未生效]`

---

#### 四、不足额付款处理

**摘录要点**：
- 发包人部分付款时的清偿顺序约定
- 多期欠款并存时的抵充规则

**裁判规则**：
- 无特别约定时 → 司法清偿顺序：先抵利息，后抵本金 `[裁判规则]`
- 发包人单方指定抵充某笔欠款 → 承包人不认可时可主张按法定顺序
- 部分付款构成债务承认 → 导致该笔债权的诉讼时效中断

---

#### 五、付款前置条件

**摘录要点**：
- 付款报审资料清单（进度款报审表/工程量清单/质检报告等）
- 验收前置要求（分部分项验收合格后方可申请付款）
- 开票前置（先票后款——承包人先开票、发包人后付款）
- 审计前置（审计结论作为付款前提）
- 付款审核期限（发包人/监理审核报审资料的时间限制）

**风险点**：
- 审计前置条款 → 发包人可无限拖延审计
- 付款审核期限过长 → 实质拖延付款
- 前置条件过于苛刻 → 承包人难以满足，付款无限延迟

**裁判规则**：
- 审计前置条款有效，但发包人不得恶意拖延审计
- 无约定付款期限的按司法解释一第 27 条确定起算时点 `[法条原文]`
- 2025示范文本新增逾期审核视为认可条款（12.4.4条），倒逼发包人及时审核 `[征求意见稿]` `[未生效]`

---

#### 六、扣款协同机制

**当期应付净额公式**：
```
当期应付净额 = 已完合格工程量价款 + 调价差 + 签证增量 + 变更增加 + 索赔价款
              - 质保金暂扣 - 甲供材扣款 - 水电费扣款 - 违约金罚款
              - 超领材料扣款 - 前期超付抵扣 - 代缴费用
```

**摘录要点**：
- 各项扣款的合同依据和计算方式
- 扣款顺序（质保金先扣/罚款先扣/甲供材先扣）
- 扣款异议程序（承包人对扣款有异议时的处理流程）

**风险点**：
- 多项扣款叠加 → 当期实际到账金额远低于预期，现金流枯竭
- 扣款依据不明确 → 发包人随意扣款，承包人事后维权困难
- 发包人单方扣款未通知 → 承包人当期收到的金额与预期不符，影响后续施工安排

**关联条款**：C22 甲供材/甲控材条款（甲供材扣款计算）、C8 缺陷责任与质保条款（质保金比例/返还）、module-2 款项核算（台账生成和利息计算）

---

### C10. 变更/签证/洽商条款

**摘录要点**：
- 工程变更的提出和审批流程
- 签证签字主体（授权代表）
- 逾期签证默认认可的默示条款
- 增量价款的结算规则

**风险点**：
- 签证签字人权限不明确 → 发包人不认可
- 逾期不予签证不构成默认认可 → 承包人权利落空
- 增量价款计算方法不明确 → 结算争议

**裁判规则**：
- 口头变更形成事实认可的 → 可认定为有效变更
- 发包人默示接受变更 → 视为认可

**★ 2025示范文本更新**：2025版施工合同示范文本在19.7条增设**索赔失权例外条款**，保护承包人不会因逾期提交索赔通知而当然丧失索赔权利。这是对原FIDIC/示范文本严格28天索赔通知规则的重要缓和。 `[征求意见稿]` `[未生效]`

---

### C11. 转包/分包/挂靠禁止

**摘录要点**：
- 禁止转包的明确约定
- 允许的分包范围和条件
- 挂靠/借照经营的禁止
- 违法转包/分包的后果（没收管理费/罚款/解除合同）

**风险点**：
- 挂靠经营 → 合同无效
- 违法分包 → 分包合同无效 + 管理费被没收
- 转包 → 合同无效 + 承包人丧失价款优先受偿权

**裁判规则**：
- 转包合同无效 → 实际施工人可向发包人主张权利
- 违法分包 → 分包人无权要求工程款（只能主张实际支出的折价补偿）

---

### C12. 合同解除/终止条款

**摘录要点**：
- 发包人单方解除事由（质量严重不合格/工期严重逾期/转包等）
- 承包人单方解除事由（长期不付款/不提供施工条件等）
- 解除程序和通知要求
- 解除后的价款结算/退场/停工损失

**风险点**：
- 解除条件过于宽泛 → 对方可轻易解除
- 退场结算方式不明确 → 已完工程价款争议
- 未约定退场期限 → 承包人拖延退场

**裁判规则**：
- 解除后 → 已完工程质量合格的，发包人应付相应工程款
- 一方过错导致解除 → 过错方赔偿对方损失

---

### C13. 送达与默示条款

**摘录要点**：
- 各方法律文书送达地址
- 签收规则（签收日/退回日视为送达）
- 各类通知/催告的默示规则（逾期不回复视为认可/不认可）

**风险点**：
- 送达地址变更未通知 → 原地址送达仍有效
- 默示认可条款 → 发包人/承包人可能无意中认可不利事实
- 邮件/微信送达是否构成有效送达

**裁判规则**：
- 合同约定的送达地址 → 法院/仲裁认可
- 默示条款有效性以"合理期间"为前提（过短的默示期可能被认定为无效）

## 输出格式

条款分析完成后，Agent 应输出以下格式的汇总表：

```markdown
## 合同条款分析汇总

| 编号 | 条款类型 | 约定情况 | 风险等级 | 主要风险 | 法律依据 |
|------|---------|---------|---------|---------|---------|
```

### C14. 背靠背付款条款

**定义**：总包/分包合同中约定，总包收到发包人付款后再支付分包人或总包按发包人付款比例向分包人付款的条款。

**摘录要点**：
- 付款节点的表述（收到业主付款后按业主付款比例随业主付款等）
- 总包对分包人的付款义务是否独立于发包人付款
- 总包是否承担发包人拒付/迟付风险

**效力认定（核心争议）**：
| 观点 | 依据 | 裁判倾向 |
|------|------|---------|
| 有效（契约自由） | 合同双方意思自治，分包人知悉并同意 | 少见，仅适用于分包人实力强且明确接受 |
| 无效（违反正义） | 转嫁发包人信用风险给分包人违反公平原则；分包人无法控制发包人付款 | 主流观点  |
| 附条件但可抗辩 | 总包不能证明已积极向发包人主张权利时，不得以该条款抗辩 | 折中立场（部分高院） |

**裁判规则**：
- 总包以背靠背条款抗辩 → 须举证已向发包人积极主张权利（起诉/仲裁/催告）
- 总包怠于向发包人追索 → 视为付款条件已成就
- 发包人已破产/丧失履约能力 → 总包不得以未收到付款为由拒付分包人
- 分段付款的背靠背条款 → 酌定总包已收到部分时按比例支付

**应对策略**：
- 分包人：签约时力争删除或增加最多不超过X月内付款的上限
- 总包：保留向发包人催款/起诉/仲裁的全套证据链 


### C15. EPC/DB 总承包特有条款分析

**适用范围**：设计采购施工总承包（EPC）/ 设计施工总承包（DB）合同。

**与施工合同的关键差异**：

| 维度 | 施工合同 | EPC/DB 总承包 |
|------|---------|--------------|
| 承包范围 | 仅施工 | 设计+采购+施工/设计+施工 |
| 计价模式 | 以施工图为依据 | 以业主要求/功能描述为依据 |
| 设计责任 | 发包人提供图纸 | 承包人自行设计并对设计负责 |
| 变更认定 | 图纸变更→变更签证 | 业主需求变更→变更（范围更窄） |
| 固定总价范围 | 工程量清单范围内 | 业主要求范围内（范围更宽） |
| 司法解释适用 | 明确适用 | 存在争议  |

**EPC 特有争议点**：

| 争议类型 | 分析要点 |
|---------|---------|
| 司法解释是否适用 | 2025年征求意见稿已删除总承包参照施工合同条款，适用性存在不确定性   |
| 固定总价范围认定 | EPC固定总价通常含设计、采购、施工全部费用；业主变更需求时才调整 |
| 设计缺陷责任归属 | EPC模式下设计由承包人完成，设计缺陷一般属承包人责任（除非业主要求本身错误） |
| 未竣工结算方法 | 因无施工图，定额比例法难以适用 → 更可能采用成本法/评估法 |
| 性能考核标准 | EPC项目有性能考核（performance test），未达标时承包人的违约责任 |

**摘录要点**：
- 业主需求说明（Employer's Requirements）的完整性和准确性
- 固定总价包含的范围（哪些属于包干、哪些可以调价）
- 设计标准和规范（中国标准/国际标准/业主要求）
- 性能考核标准及其未达标的后果
- 变更程序（与施工合同不同，EPC变更门槛更高）
- 分包限制（EPC合同通常限制承包人将设计分包）

**风险点**：
- 业主需求说明模糊 → 承包范围不确定，总价包含哪些内容有争议
- 未约定地质条件风险承担 → 不利地质条件可能由承包人自担
- 性能考核标准过高 → 可能无法通过，承担违约责任
- 当地规范适用不明 → 中国规范 vs 国际规范冲突

**裁判倾向**：
- EPC合同纠纷优先适用合同约定，司法解释仅作参考 
- 固定总价一般不轻易突破，除非业主变更需求导致范围扩大
- 设计缺陷责任一般由承包人承担，但业主要求错误导致的除外


### C16. 联合体承包条款 ★v2.1新增

**适用范围**：两家或以上承包人组成联合体（Joint Venture / Consortium）共同投标和承包工程。

**摘录要点**：
- 联合体成员及各自分工（设计方/施工方/采购方/设备供应方）
- 牵头方（主办方）职权范围（协调/管理/代为签约？）
- 各方对发包人的责任形式（连带责任/按份/连带但有内部追偿比例）
- 对下游分包商/供应商的责任承担方式
- 联合体协议的对外效力
- 退出/更换联合体成员的机制

**风险点**：
- 一方无资质 → 联合体整体投标无效、合同无效（2025典型案例）
- 联合体内部协议对发包人无约束力 → 发包人可任选一方追偿
- 内部责任划分不清 → 成员间追偿纠纷
- 牵头方越权签约 → 表见代理风险（出借企业承担民事责任）
- 一方退出后其余方能否继续履约

**裁判规则**：
- 联合体各方对发包人承担连带责任（《招标投标法》第31条） `[法条原文]`
- 联合体资质"就低不就高"原则——仅一方有资质不能满足招标要求
- 联合体对下游分包商/供应商的责任以合同约定为限，无约定时遵循合同相对性原则 `[裁判规则]`

**关联条款**：C11 转包/分包/挂靠禁止（联合体内部再分包给成员的合规性）


### C17. 甲指分包/指定分包条款 ★v2.1新增 ★2025新规

**定义**：发包人指定承包人将部分工程分包给特定的分包商（甲指分包），承包人以自己名义与指定分包商签订分包合同。

**摘录要点**：
- 是否存在发包人指定分包商/供应商的条款
- 承包人对指定分包商的管理权限和配合义务
- 指定分包商的付款路径（经承包人支付/发包人直接支付）
- 指定分包商违约/质量不合格/工期延误的责任归属
- 总包管理费/配合费的约定

**风险点（★ 2025新规重点关注）**：
- 发包人指定分包 → 可能被认定发包人与实际施工人形成**直接合同关系** `[征求意见稿]` `[未生效]`
- 承包人"代收代付" → 可能承担不必要的付款义务
- 指定分包商违约 → 责任归属争议（发包人："你总包管理的" vs 承包人："你指定的"）
- 发包人指定供应商 → 材料质量缺陷的责任分配
- 甲指分包的管理费不足以覆盖总包管理成本

**裁判规则（★ 2025新规）**：
- 发包人指定分包的，承包人与实际施工人之间的分包合同属于虚假意思表示，无效 `[征求意见稿]` `[未生效]`
- 此种情形下，发包人与实际施工人之间形成**直接合同关系** `[征求意见稿]` `[未生效]`
- 承包人未实际参与施工管理的，不承担付款义务 `[征求意见稿]` `[未生效]`
- 承包人实际参与管理的，仅在其管理范围内承担责任

**应对策略**：
- 承包人：签约时明确约定"指定分包商违约/质量问题由发包人承担"
- 发包人：如必须指定分包，应在合同中明确承包人的管理责任和配合义务
- 实际施工人：保留与发包人直接沟通的记录，证明发包人知悉并主导分包


### C18. 垫资与垫资利息条款 ★v2.1新增

**定义**：承包人先行投入资金进行施工，发包人在后续节点返还垫资及利息的约定。

**摘录要点**：
- 垫资金额或比例（如"承包人垫资至主体结构封顶""垫资合同价的30%"）
- 垫资期限（垫资到何时为止/垫资额度上限）
- 垫资利息约定（利率/起算时间/计息方式）
- 垫资返还节点和方式（进度款中分批返还/结算时一次性返还）
- 逾期返还垫资的违约责任
- 垫资担保（如有）

**风险点**：
- 垫资利息未约定 → 按工程欠款处理，无法主张垫资期内的资金成本（司法解释一第25条） `[法条原文]`
- 垫资利率过高 → 超出LPR四倍部分可能被调整
- 垫资返还节点模糊 → 发包人长期占用承包人资金
- 垫资无担保 → 发包人破产时承包人仅为普通债权人
- 垫资约定不明 → 被认定为"工程欠款"而非"垫资"，利息计算方式不同

**裁判规则**：
- 垫资条款有效的，按约定处理垫资本金和利息
- 对垫资利息无约定的，不予支持（司法解释一第25条） `[法条原文]`
- 对垫资返还期限无约定的，按工程欠款处理，利息起算适用司法解释一第27条
- 垫资利率高于合同约定利率的，以约定为准；无约定利率的，按同期LPR

**关联条款**：C1 造价模式（垫资常与固定总价模式并存）、C9 价款支付条款


### C19. 履约担保与支付担保条款 ★v2.1新增

**定义**：履约担保是承包人向发包人提供的保证按约履行合同的担保；支付担保是发包人向承包人提供的保证按约支付工程款的担保。

**摘录要点**：
- 履约担保形式（银行保函/担保公司保函/保证金/保险保证）
- 履约担保金额（通常合同价5%-10%）
- 支付担保形式与金额（2025示范文本推动强制化）
- 保函有效期（是否覆盖缺陷责任期？是否覆盖保修期？）
- 保函递减/释放机制（进度款支付后逐步释放担保金额）
- 见索即付保函（无条件保函）vs 有条件保函
- 保函到期续保义务

**风险点**：
- 履约保函无递减机制 → 全额担保持续到项目结束，占用承包人授信额度
- 发包人不提供对等支付担保 → 承包人单方承担担保成本
- 见索即付保函 → 发包人可无条件索赔（存在滥用风险，可能被迫申请止付令）
- 保函到期未续 → 构成承包人违约，发包人可能以此为由暂停付款或解除合同
- 保函索赔条件过于宽泛 → 发包人可轻易索赔
- 支付担保缺失 → 发包人无付款压力，拖欠概率增大

**裁判规则**：
- 2025版施工合同示范文本推动支付担保强制化，要求发包人提供对等支付担保 `[征求意见稿]` `[未生效]`
- 见索即付保函可申请止付令（需证明欺诈或滥用——举证标准高） `[裁判规则]`
- 保函到期后未续保，发包人可依约索赔或暂停付款

**谈判策略**：
- 承包人：力争履约保函金额随进度款支付而递减（如"进度款支付至80%时保函金额减至50%"）
- 承包人：要求发包人提供对等支付担保，避免单方负担
- 发包人：避免使用见索即付保函，选择有条件保函以控制索赔风险


### C20. 农民工工资保障条款 ★v2.1新增

**定义**：依据《保障农民工工资支付条例》（2020年5月1日施行）要求，施工合同中关于农民工实名制管理、工资专用账户、工资保证金和总包代发制度的约定。

**摘录要点**：
- 农民工实名制管理义务（人员登记/考勤/工资卡绑定）
- 工资专用账户条款（专户开设/资金拨付/银行代发）
- 工资保证金存储方式和金额
- 总包代发制度（分包委托总包代发/总包监督分包发放）
- 违反工资保障义务的违约责任
- 工资支付台账和公示要求

**风险点**：
- 未落实实名制 → 行政处罚（项目停工/限制市场准入）+ 工资数额无法核实
- 总包未监督或代发分包工资 → 对分包拖欠的农民工工资承担**先行清偿责任**
- 工资保证金不足/未存储 → 施工许可证不予核发或项目停工
- 分包拖欠农民工工资 → 总包先行清偿后向分包追偿困难
- 工资专户资金被挪用 → 企业和直接责任人面临行政处罚

**裁判规则**：
- 农民工可直接向建设单位、施工总承包单位主张工资（不论转包/分包是否合法） `[法条原文]`
- 总包对分包单位拖欠的农民工工资承担先行清偿责任 `[法条原文]`
- 因建设单位未按约支付工程款导致拖欠农民工工资的，建设单位以未付工程款为限先行垫付 `[法条原文]`
- 工资专用账户内的资金不得因本项目以外的债务被查封、冻结或划拨

**关联条款**：C9 价款支付条款、C11 转包/分包/挂靠禁止


### C21. 保险条款 ★v2.1新增

**定义**：施工合同中约定的各类工程保险的购买、维护和理赔责任分配。

**摘录要点**：
- 工程一切险（投保人/被保险人/受益人/保险金额/免赔额/保险期间）
- 第三方责任险（每次事故/累计赔偿限额）
- 人身意外伤害险（投保对象/保险金额/受益人）
- 安装工程一切险（设备安装项目特有）
- 职业责任险（设计方/监理方）
- 保险购买义务归属和费用承担
- 未投保/保额不足/理赔被拒的责任分配
- 保险事故后的通知和处理流程

**风险点**：
- 保险由承包人购买但费用未约定 → 费用归属争议
- 保险期间不覆盖缺陷责任期/保修期 → 缺陷期内事故无保险保障
- 免赔额由谁承担 → 小额事故的责任推诿
- 一方不配合保险理赔 → 导致理赔被拒，损失扩大
- 保额不足以覆盖实际损失 → 差额由谁承担
- 承包人未按约购买保险 → 事故后发包人可主张承包人未购买保险的违约责任

**裁判规则**：
- 未投保不影响侵权责任的构成——未购买保险不妨碍受害方向责任方索赔
- 保险合同约定的理赔范围不当然影响发包人/承包人之间的责任分配
### C22. 甲供材/甲控材条款 ★v2.1新增

**定义**：甲供材（甲指乙供）是发包人自行采购并提供给承包人的材料设备；甲控材是发包人指定品牌/规格/供应商，由承包人自行采购的材料设备。

**摘录要点**：
- 甲供材清单（材料名称/规格/数量/供应时间节点）
- 甲供材供应不及时的工期顺延约定
- 甲供材质量缺陷的责任归属
- 甲供材到场后的检验义务（检验时限/检验标准/不合格处理）
- 甲供材损耗率（合同约定损耗率/超领扣款标准）
- 甲控材的指定范围（品牌/供应商名单）和替代程序
- 甲供材/甲控材的保管责任归属

**风险点**：
- 甲供材供应不及时 → 工期延误，承包人能否顺延工期（看合同约定）
- 甲供材质量缺陷 → 工程不合格责任谁承担（承包人未尽检验义务则可能分担责任）
- 甲供材超领 → 发包人从工程款中扣款，但定额消耗量标准可能争议
- 甲控材品牌指定 → 价格高于市场价、供应短缺时承包人无替代空间
- 未约定甲供材清单 → 施工中临时指定甲供材，打乱承包人采购计划
- 甲供材保管不善 → 损失由保管方承担

**裁判规则**：
- 发包人提供的材料不符合约定 → 承包人可拒绝使用并要求更换（《民法典》第775条） `[法条原文]`
- 承包人对甲供材有检验义务 → 发现不符合约定应及时通知；怠于通知视为甲供材合格 `[法条原文]`
- 甲供材质量缺陷导致的工程不合格 → 发包人承担主要责任（但承包人有过错的，按过错分担）
- 甲供材供应不及时属于发包人原因 → 工期可顺延，费用由发包人承担（但合同另有约定除外）
- 甲控材指定供应商断供/涨价 → 承包人可要求发包人更换指定品牌或调整价格（以合同约定为前提）

**关联条款**：C9 价款支付条款（付款安排直接影响甲供材扣款后当期应付净额）、C2 工程质量条款（甲供材质量影响工程质量）

**与 module-2 的衔接**：甲供材扣款金额计算详见 `references/module-2-payments.md`（当期甲供材扣款 = 领用量 × 单价）


### C23. 竣工验收与移交程序条款 ★v2.1新增

**定义**：竣工验收是确认工程已按合同约定完成并符合质量标准的法定程序；移交是承包人将工程现场移交给发包人的行为。

**摘录要点**：
- 竣工验收条件（工程按约完成/资料齐备/清理现场等）
- 竣工验收程序（承包人申请→发包人组织验收→出具验收报告）
- 发包人审核验收申请的期限（合同约定/无约定则28天）
- 拖延验收的后果（逾期视为认可/竣工日期前移）
- 竣工日期认定规则
- 工程移交条件（资料移交清单/现场移交标准/钥匙移交）
- 甩项验收（部分未完工但发包人要求先行使用）
- 未竣工擅自使用的责任
- 竣工验收备案（向建设行政主管部门备案的义务方和时限）

**风险点**：
- 发包人无正当理由拖延验收 → 竣工日期前移至承包人提交验收报告之日
- 未经验收擅自使用 → 视为质量合格（地基基础和主体结构除外）→ 发包人丧失质量异议权
- 验收资料不完整 → 承包人反复补报，验收程序拖延
- 甩项验收边界不清 → 已用部分和未用部分的保修起算、质保金返还节点混乱
- 移交后质量问题 → 移交后新发现的质量缺陷属于保修责任还是验收遗漏？
- 发包人不配合竣工验收备案 → 影响不动产权登记

**裁判规则**：
- 竣工验收合格之日为竣工日期（司法解释一第9条） `[法条原文]`
- 发包人拖延验收 → 承包人提交验收报告之日为竣工日期 `[法条原文]`
- 发包人擅自使用 → 转移占有之日为竣工日期，且不得以使用部分质量不合格为由拒付（地基基础和主体结构除外） `[法条原文]`
- 多单体工程 → 各单体分别认定竣工日期，合同另有约定从约定
- 甩项验收 → 发包人要求部分未完工先行使用的，甩项验收合格日为该部分竣工日
- 发包人不配合办理竣工验收备案 → 承包人可请求法院确认工程已竣工

**关联条款**：C2 工程质量条款（验收标准）、C3 工期条款（竣工日期直接影响工期违约金计算）、C8 缺陷责任与质保条款（缺陷责任期从竣工验收合格日起算）
