# 标准化输出模板

本文件定义各交付物的详细内部结构。所有输出遵循以下规则：
- Markdown 格式：标题用 `#` / `##` / `###` 层级，表格用 `|`，代码块用 ```
- .xlsx 格式：仅限工程款利息台账、证据目录
- 来源标签：法律引用必须标注 `[法条原文]` `[司法解释]` `[裁判规则]` `[需验证]`
- 关键判断：主观结论标注 `[需审查]`
- 免责声明：所有输出尾部附律师审查草稿声明

---
