# 模块六：结算与质保金专项

## 触发条件

用户提到：结算、竣工结算、质保金、缺陷责任、保修、返还质保金、中途结算、退场结算、未竣工

## 竣工结算流程

> **条款交叉引用**：竣工验收程序、竣工日期认定、拖延验收后果等详见 `references/module-1-clauses.md` C23（竣工验收与移交程序条款）。本节聚焦结算款支付节点和金额核算。

1. 承包人提交竣工结算文件
2. 发包人审核（合同约定的审核期限，无约定则 28 天）
3. 发包人逾期不答复 → 视为认可结算文件（需合同有明确约定）
4. 发包人支付结算款

## 质保金管理

### 基本规则

- 质保金比例：一般不超工程价款总额的 **3%**
- 缺陷责任期：通常 **1-2 年**（合同约定）
- 保修期：法定期限（地基基础和主体结构为设计文件合理使用年限）

### 质保金返还节点

```
缺陷责任期届满 → 发包人应返还质保金
   ├── 第一节点（通常竣工验收后 1 年）：返还一定比例 (如 50-80%)
   └── 第二节点（通常竣工验收后 2 年）：返还剩余部分

逾期返还 → 按同期 LPR 计息
```

### 缺陷修复抵扣

- 承包人不履行缺陷修复义务 → 发包人可自行或委托第三方修复 → 费用从质保金中抵扣
- 发包人应通知承包人修复并给予合理期限
- 紧急情况下发包人可先行修复后通知

## 未竣工工程结算

### 中途解约/退场

1. 对已完工程质量进行确认和验收
2. 按合同约定的计价方式折算已完工程价款
3. 未施工部分的预期利润一般不赔
4. 已采购未使用材料的处理（纳入结算/承包人自行处理）
5. 临时设施/机械退场费的承担

### 未完工程价款扣减

```
合同总价 - 未完工程部分价款 = 已完工程应付款
（未完部分价款 = 合同报价中的相应项目价款，非简单比例扣除）
```

## 输出要求

- 结算时间线梳理
- 质保金返还节点计算
- 缺陷修复费用核算
- 未结算/逾期结算的利息主张


## 审计条款约束力

### 条款类型

| 类型 | 表述 | 效力倾向 |
|------|------|---------|
| 强制性审计条款 | 结算以政府审计结论为准 | 有限有效  |
| 约定性审计条款 | 结算报审计部门审核 | 仅为程序性约定 |
| 无审计约定 | 合同未提及审计 | 审计结论不当然约束双方 |

### 核心规则

- 审计条款并非当然约束民事结算：政府审计是国家对建设单位财政投资的行政监督，不当然约束施工合同的结算  
- 约定以审计结论为准的，审计结论不实时可申请司法鉴定（审价远超合理期限或明显偏离合同约定） 
- 审计条款仅约束合同当事人，不约束分包人、实际施工人
- 审计结论仅对报告中载明的部分有约束力，审计报告中未经质证的材料不得作为定案依据

### 应对策略

- 承包人：签约时反对以审计为准条款，或增加最长审计期限和超期默示认可
- 发包人：如需以审计为条件，应明确约定审计结论对双方的约束力


## 未完工工程结算方法

### 中途解约/退场结算

| 方法 | 适用场景 | 计算方式 | 裁判倾向 |
|------|---------|---------|---------|
| 定额比例法 | 固定总价合同未完工程 | 已完部分定额造价/全部定额造价×固定总价 | 主流方法  |
| 反向扣除法 | 未完部分明确可计价 | 固定总价 - 未完工程合同价款 | 适用于清单计价 |
| 定额计算法 | 无法适用比例时 | 对已完工程重新按定额计价 | 适用于合同无效 |
| 成本加利润法 | EPC/DB 未竣工 | 实际成本 + 合理利润 | EPC适用 |

### 计算示例（定额比例法）

```
假设：
- 固定总价合同：¥50,000,000
- 已完工程定额造价：¥32,000,000（按定额标准计算的已完部分造价）
- 全部工程定额造价：¥48,000,000（按定额标准计算的全部工程造价）

已完工程结算价 = ¥50,000,000 × (¥32,000,000 / ¥48,000,000) = ¥33,333,333

如已支付：¥28,000,000
尚欠：¥33,333,333 - ¥28,000,000 = ¥5,333,333
```

### 关键注意点

- 定额比例法不考虑各部分利润率的差异（实际利润率高的部分先完工对承包人有利，反之不利）
- 发包人原因导致合同解除 → 承包人可主张已完工程款 + 停工损失 + 合理利润
- 承包人原因导致合同解除 → 已完工程款照付，但发包人可主张另行发包增加的费用


## 缺陷责任期 vs 工程保修期

| 对比项 | 缺陷责任期 | 工程保修期 |
|--------|-----------|-----------|
| **性质** | 质量保证金的质押期限 | 承包人的质量保修义务期限 |
| **起算日** | 竣工验收合格之日 | 竣工验收合格之日 |
| **期限** | 通常1-2年（合同约定）| 法定期限（地基主体：设计年限；防水：5年；装修：2年等）|
| **届满后果** | 质保金应予返还 | 保修义务继续存在 |
| **法律依据** | 《建设工程质量保证金管理办法》| 《建设工程质量管理条例》第40条 |

### 实务处理规则

- 缺陷责任期届满 ≠ 保修期届满：质保金应返还，但保修义务持续
- 两个期限可以并行计算（缺陷责任期包含在保修期内）
- 缺陷责任期内 → 发包人可直接从质保金中扣除修复费用
- 缺陷责任期届满后、保修期内 → 发包人需另行主张修复费用，不能直接从质保金扣除
- 发包人未通知承包人修复即委托第三方修复的，修复费用可能不被支持

### 常见争议

| 争议点 | 裁判倾向 |
|--------|---------|
| 合同约定的缺陷责任期超过2年 | 超过部分无效（部门规章层面）|
| 质保金返还后出现质量缺陷 | 承包人的保修责任不受影响 |
| 发包人未通知即自行修复 | 修复费用发包人自行承担 |
