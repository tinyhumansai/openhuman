# 模块五：索赔与反诉抗辩

## 触发条件

用户提到：索赔、反诉、抗辩、停工损失、窝工费、材料涨价损失、工期顺延索赔、抵消、互负债务

## 承包方索赔（乙方 → 甲方）

| 索赔类型 | 计算依据 | 关键证据 |
|---------|---------|---------|
| 逾期付款利息 | 欠付本金 × LPR × 逾期天数 / 365 | 付款凭证、合同付款条款 |
| 停工损失 | 人工窝工费 + 机械停滞费 + 管理费 | 停工通知、考勤记录、机械台账 |
| 窝工损失 | 窝工人数 × 工日单价 × 窝工天数 | 人员考勤、工资单 |
| 材料涨价损失 | 超出风险包干幅度的材料价差 | 采购合同、发票、信息价 |
| 工期顺延 | 非承包人原因延误的天数 | 停工令/复工令/甲方指令 |
| 提前竣工奖 | 合同约定的提前竣工奖励 | 合同条款、竣工证明 |

## 发包方抗辩/反诉（甲方 → 乙方）

| 抗辩/反诉类型 | 计算依据 | 关键证据 |
|-------------|---------|---------|
| 工期违约金 | 逾期天数 × 日违约金标准 | 合同条款、实际竣工日期 |
| 质量修复费用 | 修复方案造价，或实际修复支出 | 鉴定报告、修复合同、付款凭证 |
| 超付工程款返还 | 实际已完合格工程量对应的价款 - 已付款 | 造价鉴定、付款凭证 |
| 违约损失赔偿 | 因承包人违约造成的实际损失 | 损失证明材料 |
| 甲供材超领扣款 | 领用量 - 定额用量 × 单价 | 领料单、定额计算 |

## 抵消规则

### 法定抵消（民法典第 568 条）

- 双方互负到期债务
- 标的物种类、品质相同（金钱债务）
- 任何一方可主张抵消
- 通知到达对方时生效

### 计算示例

```
承包方索赔:
  逾期付款利息: ¥670,000
  停工损失: ¥850,000
  合计: ¥1,520,000

发包方反诉:
  工期违约金: ¥1,200,000
  质量修复费: ¥300,000
  合计: ¥1,500,000

抵消后: 发包方净应付承包方 ¥20,000
```

## 输出要求

每项索赔/抗辩输出：权利依据（合同条款/法律规定）→ 事实基础 → 金额计算明细 → 证据支撑


## 发包人索赔专章（甲方 → 乙方）

### 工期违约金逐日计算

```
工期违约金 = 逾期天数 × 日违约金标准

日违约金标准：合同约定（通常为合同总价的万分之三至万分之五）
逾期天数 = 实际竣工日 - 合同约定竣工日 - 合理顺延天数

法院调整原则：
- 违约金总额一般不超合同价款的 5%（部分地区参考）
- 违约金 > 损失的 130% → 可申请减少（民法典第585条）[法条原文]
- 施工合同工期违约金的调整空间小于一般民事合同（工期延误损失难以精确量化）
```

**计算示例**：
```
合同总价：¥50,000,000
日违约金标准：万分之四（¥20,000/天）
逾期天数：120天
法院调整上限：合同价5% = ¥2,500,000

计算违约金：120 × ¥20,000 = ¥2,400,000
结论：¥2,400,000 < ¥2,500,000，不需要调整
```

### 质量修复费用核算

**核算公式**：
```
质量修复费用 = 材料费 + 人工费 + 机械费 + 管理费 + 合理利润

材料费 = 修复方案材料清单 × 市场单价
人工费 = 修复所需工日 × 工日单价
机械费 = 修复所需台班 × 台班单价
管理费 = (材料费 + 人工费 + 机械费) × 管理费率（通常5-8%）
合理利润 = (材料费 + 人工费 + 机械费 + 管理费) × 利润率（通常5-8%）
```

**关键证据**：
- 鉴定机构出具的修复方案和造价鉴定报告
- 发包人自行修复的：修复合同 + 付款凭证 + 修复前后照片
- 发包人委托第三方修复的：委托合同 + 付款凭证 + 修复验收记录
- **必须**先通知承包人修复并给予合理期限（紧急情况除外）

### 甲供材超领扣款

**计算方式**：
```
甲供材超领扣款 = (实际领用量 - 定额用量) × 材料单价

定额用量 = 已完工程量 × 定额消耗量系数
实际领用量 = 领料单累计数量
```

**举证要点**：
- 发包人需提供：领料单（有承包人签字）+ 材料采购合同/发票证明单价
- 承包人抗辩：定额消耗量系数不合理 + 领料单签字人不具有权限 + 材料损耗属于正常范围

### 另行发包增加费用索赔

发包人因承包人违约而解除合同后，将未完工程另行发包给第三方，可索赔：
```
另行发包增加费用 = 新合同价格 - 原合同未完部分价格
```

**限制条件**：
- 发包人须以合理方式选择新承包人（不可恶意高价发包）
- 价格对比应以"同等范围和标准"为基础


## 停工/窝工损失详细计算方法 ★v2.1新增

### 五种损失类型及计算公式

#### 1. 人员窝工费
```
人员窝工费 = Σ(窝工人数 × 日工资单价 × 窝工天数 × 窝工系数)

窝工系数说明：
- 完全停工：窝工系数 = 1.0
- 部分停工（降效施工）：窝工系数 = 0.3-0.6（根据实际降效程度）
- 管理人员：一般按100%
- 施工工人：转场或遣散后不再计算

日工资单价 = 合同约定日工资 或 实际支付工资/实际出勤天数
```

#### 2. 机械停滞费
```
自有机械停滞费 = Σ(停滞台班 × 停滞台班折旧费)
租赁机械停滞费 = Σ(停滞台班 × 日租赁费)

注意：
- 自有机械仅计折旧费，不计台班全费（因未实际运转）
- 租赁机械按租赁合同约定的日租赁费计算（需提供租赁合同）
- 机械停滞期间如转场使用，不得重复计取
```

#### 3. 材料积压损失
```
材料积压损失 = 已购材料资金占用利息 + 材料仓储保管费

资金占用利息 = 已购材料价值 × LPR × 积压天数 / 365
仓储保管费 = 实际支付的仓储费用（需提供合同和付款凭证）

注意：
- 已购材料须为该项目专用且无法退换
- 停工后承包人应及时处理可退换/转用的材料（减损义务）
- 因未及时处理导致的扩大损失，发包人不予赔偿
```

#### 4. 现场管理费
```
现场管理费 = 停工期间现场管理费实际支出

包括：
- 管理人员工资（停工期间留守人员）
- 现场水电费（基本维护）
- 临时设施维护费
- 安保费用

不包括：
- 已遣散/转场人员工资
- 非停工必需的其他费用
```

#### 5. 周转材料租赁费
```
周转材料租赁费 = Σ(租赁材料数量 × 日租赁单价 × 停工天数)

包括：模板、脚手架钢管、扣件等租赁材料
需提供：租赁合同 + 出库单 + 停工期间未归还的证明材料
```

### 停工损失举证要点

| 损失类型 | 关键证据 |
|---------|---------|
| 人员窝工费 | 考勤记录/工资发放表/劳务合同（证明人数和工资标准） |
| 机械停滞费 | 机械台账/租赁合同/进退场记录 |
| 材料积压 | 采购合同/入库单/仓储合同/付款凭证 |
| 管理费 | 管理人员工资单/水电费账单/安保合同 |
| 周转材料 | 租赁合同/出库单/结算单 |

**共同前提**：停工原因归属发包人（停工通知/会议纪要/监理记录）


## 索赔通知时效分析 ★v2.1新增

### 28天索赔通知规则

FIDIC合同条件和国内示范文本通常规定：
- 索赔事件发生后**28天内**提交索赔意向通知书
- 索赔事件影响结束后**28天内**提交详细索赔报告
- 逾期未提交视为放弃索赔权利（失权条款）

### 失权条款的司法审查

| 情形 | 裁判倾向 |
|------|---------|
| 发包人原因导致延误 | 承包人不因逾期申报而丧失工期顺延权利（最高法裁判规则） `[裁判规则]` |
| 双方原因（同期延误） | 需按过错比例分配，逾期申报仅影响程序不当然消灭实体权利 |
| 纯承包人原因 | 逾期申报可能失权（取决于合同明确约定） |
| 持续性事件 | 可在事件持续期间任一时间提交，影响结束后28天内提交最终报告 |

### 2025示范文本索赔失权例外

2025版施工合同示范文本（征求意见稿）19.7条增设索赔失权例外条款，保护承包人不会因逾期提交索赔通知而当然丧失索赔权利。 `[征求意见稿]` `[未生效]`

### 时效中断的索赔作用

- 发送索赔函/催告函 → 诉讼时效中断（民法典第195条 [法条原文]）
- 对方书面/部分付款/承诺还款 → 时效中断
- 起诉/仲裁 → 时效中断，重新起算
- 建议：每6-12个月发送一次书面催告函以持续中断时效


## 同期延误分析方法 ★v2.1新增

### 定义

同期延误（Concurrent Delay）是指在同一时间段内，发包人和承包人双方均存在导致工期延误的原因。

### 常用分析方法

#### 方法一：Window Analysis（窗口分析法）

```
1. 将整个工期划分为多个分析窗口（通常按月或按事件分）
2. 在每个窗口内识别：
   - 发包人原因延误天数
   - 承包人原因延误天数
   - 不可抗力延误天数
3. 逐窗口判定：
   ├── 仅有发包人原因 → 工期顺延 + 费用补偿
   ├── 仅有承包人原因 → 不顺延 + 违约金
   ├── 双方原因 → 按过错比例分配（部分顺延）
   └── 不可抗力 → 工期顺延、各自承担费用
```

#### 方法二：As-Planned vs As-Built（计划vs实际对比法）

```
1. 以原始施工进度计划为基线（As-Planned）
2. 逐项对比实际施工进度（As-Built）
3. 识别关键路径上的每一项延误：
   - 延误原因归属
   - 延误是否在关键路径上（非关键路径延误不影响竣工日期）
   - 是否与其他延误同期发生
4. 叠加计算净延误天数
```

#### 方法三：Snapshot Method（快照法）

```
选取关键时间节点（如每月末/每季度末），记录当时的：
- 计划完成进度 vs 实际完成进度
- 已发生的延误事件及原因
- 关键路径状态
逐"快照"分析延误的累积效应
```

### 同期延误的裁判倾向

| 情形 | 裁判倾向 |
|------|---------|
| 双方原因同期发生且无法区分 | 各承担50%（部分法院）或工期顺延但不赔偿费用 |
| 发包人原因 + 不可抗力同期 | 工期顺延，发包人赔偿其自身原因造成的损失 |
| 承包人原因 + 不可抗力同期 | 工期不顺延（承包人承担其自身原因部分） `[裁判规则]` `[需验证]` |
| 多原因叠加且因果关系复杂 | 建议申请工期鉴定 [需审查] |

### 分析提示

- 同期延误分析高度依赖事实和专业判断，复杂案件建议委托工期鉴定
- 施工日志、监理日志、会议纪要是判断延误原因的基础证据
- 仅关键路径上的延误才影响竣工日期——非关键路径延误通常仅影响中间节点
- Window Analysis 是国内司法鉴定中使用最广泛的方法
