# 模块二：工程进度款核算与逾期利息计算

## 触发条件

用户提到：工程款、进度款、逾期付款、利息计算、欠付、核算台账、付款比例、付款节点、应付未付、质保金暂扣、甲供材扣款、对账

## 计算框架

### 一、进度款组成公式

```
当期应付进度款 = 已完合格工程量价款 + 可调价差 + 签证增量 + 变更增加 + 索赔价款
               - 质保金暂扣 - 甲供材扣款 - 水电费扣款 - 违约金罚款
               - 超领材料扣款 - 前期超付抵扣 - 代缴费用

当期实际欠付 = 当期应付进度款 - 当期实付金额
```

### 二、台账核心字段

#### 基础字段（必填）

| 字段 | 说明 | 数据来源 |
|------|------|---------|
| 期次 | 进度款期号（第X期） | 合同/报审资料 |
| 施工期间 | 本期施工的起止日期 | 施工日志/进度报告 |
| 已完工程量价款 | 本期完成的合格工程计价 | 报审表/工程量清单 |
| 获批金额 | 经审批确认的应付金额 | 审批文件 |
| 应支付时间 | 合同约定/法定应付款日期 | 合同条款 + 司法解释 |
| 实际支付时间 | 发包人实际付款到账日期 | 银行流水 |
| 已支付金额 | 实际到账金额 | 银行流水 |
| 延迟天数 | 应支付时间 → 实际支付时间 | 计算 |
| 适用利率 | 对应时段的 LPR（或基准利率） | LPR_TABLE 查询 |
| 当期利息 | 本金×利率×天数/365 | 计算 |

#### 新增实务必填字段（用户框架要求）

| 字段 | 说明 | 重要性 |
|------|------|--------|
| 付款前置条件完成时间 | 开票完成/报审完成/验收完成时间 | ★★ 计息起算优先依据 |
| 当期质保金暂扣 | 按合同比例暂扣金额 | ★★ 影响应付净额 |
| 当期甲供材扣款 | 发包人供应的材料费用扣回 | ★★ 影响应付净额 |
| 当期其他扣款 | 水电费/罚款/超领材料等 | ★★ 影响应付净额 |
| 当期应付净额 | 获批金额 - 各项扣款 = 实际应付款 | ★★★ 计息本金 |
| 本期欠付本金 | 当期应付净额 - 已支付金额 | ★★★ 核心数据 |
| 累计欠付余额 | 滚动累计欠款 | ★★★ 汇总数据 |
| 分段 LPR 记录 | 跨月/跨年 LPR 变动时的分段记录 | ★ 避免统一利率错误 |
| 利息抵扣记录 | 双方对账时的利息冲抵情况 | ★ 对账必需 |

### 三、计息规则

#### 计息起算日确定（优先级从高到低）

```
1. 合同有约定付款期限：
   起算日 = 约定付款日次日

2. 合同无约定付款期限：
   起算日 = 工程交付日 或 提交竣工结算文件日 或 起诉日
   （司法解释一第 27 条，按最先发生者）

3. 付款前置条件未完成：
   起算日 = 前置条件完成日次日
   （若发包人恶意阻止条件完成 → 视为条件已成就）
```

#### 计息终止日

```
终止日 = 实际付款到账日
  （部分付款 → 该部分计息至部分付款日，余额继续计息）
```

#### 分段计息规则

1. LPR 变动 → 以变动日为界分段计息，不统一套用单一利率
2. 部分付款 → 先抵利息后抵本金（司法清偿顺序）
3. 合法扣款 → 以实际应付净额为计息本金

#### 2019.8.19 之前时段

```
使用中国人民银行同期同类贷款基准利率（1 年以内）
可调用 utils.get_loan_base_rate() 查询
```

### 四、计算示例

```
假设：
- 应付金额：¥5,000,000（获批金额）
- 质保金暂扣 3%：¥150,000
- 甲供材扣款：¥0
- 应付净额：¥4,850,000
- 应支付日期：2024-03-20
- 实际支付日期：2024-08-15

计息周期：2024-03-21 ~ 2024-08-14 = 147 天

LPR 分段：
- 2024-03-21 ~ 2024-06-19 (91天) × 3.45% → 利息 = 4,850,000 × 3.45% × 91/365 = ¥41,727.53
- 2024-06-20 ~ 2024-07-21 (32天) × 3.45% → 利息 = 4,850,000 × 3.45% × 32/365 = ¥14,674.52
- 2024-07-22 ~ 2024-08-14 (24天) × 3.35% → 利息 = 4,850,000 × 3.35% × 24/365 = ¥10,684.93

总利息：¥67,086.98
```

### 五、输出要求

完成核算后，Agent 应输出：

1. **计算台账表格**（Markdown，含所有基础字段 + 新增字段）
2. **分段计息明细**（每期的 LPR 分段、天数、利息）
3. **汇总数据**：累计欠付本金、累计应付利息、累计已付利息

如需生成正式 Excel 台账，调用：
```bash
python3 scripts/generate_ledger.py --input payment_data.json --output 工程款台账.xlsx
```
