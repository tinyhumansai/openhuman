# 聊天

聊天几乎承载了所有工作。一次对话轮次可以调用工具、启动子代理、向你提问、等待审批、生成文件并记录自己的费用。聊天记录会按顺序显示整个过程。

从侧边栏打开**聊天**，或按 `⌘N` 新建对话。

## 输入框

输入框支持富文本，因此输入 `/` 时会出现命令标签，弹出菜单也会跟随光标。输入框周围还有：

- **附件**。核心接受图片、PDF、Office 文档和归档文件。聊天消息保存的是受作用域限制的不透明引用，而不是本地路径或内嵌媒体字节。每轮开始时，受信任的主机在当前轮次上下文中解析引用，并把支持的内容交给模型路由；不支持的文档类型会使用提取出的文本或归档文件列表。
- **模型**和**思考强度**。两者只影响当前对话，不会更改全局设置。
- **上下文环**。显示当前线程的上下文窗口使用情况。点击可查看明细，包括各子代理产生的费用。
- **语音**。点击即可说话，也可以把当前轮次交给实时语音代理。参见[语音](../../en/features/native-tools/voice.md)。
- **吉祥物按钮**。输入框为空时，点击会打开全屏[吉祥物](../../en/features/mascot/README.md)场景。

### 斜杠命令

输入 `/` 可查看内置命令（`/new`、`/clear`、`/stop`、`/plan`、`/build`）、核心命令，以及已安装的技能和工作流。

### 提及

输入 `@` 可搜索记忆，并查找当前线程已经生成的文件。提及会变成标签，让代理拿到明确引用，无需猜测。

## 查看一轮对话

每轮助手回复会按发生顺序，将推理和工具调用放在同一个区块中。

- 工具调用按工具类型显示。搜索会展示查询和来源；Shell 调用会显示命令和退出码；失败时显示原因而不是堆栈跟踪。所有工具都在核心中运行，不会在浏览器里运行。
- 回复下方会以徽章显示来源，最多展示四个，其余以数量表示。
- 对话轮次会显示耗时和费用。上下文环会把费用归到对应的子代理。
- **在对话中查找**（`⌘F`）只搜索当前线程。右侧边栏可在不同轮次间跳转。

助手回复可以复制、重新生成、点赞或点踩（选择会被记住）、朗读或导出为 Markdown。你也可以编辑并重新发送自己的消息；这会创建一个分支，分支选择器可切换不同版本。

## 需要你参与时

代理可能因四种原因暂停，每种情况都会在对话中显示：

| 暂停原因 | 你会看到什么 |
| --- | --- |
| 审批 | 卡片会显示工具名称和一行经过脱敏的说明。你可以批准一次、始终允许该工具，或拒绝。参见[审批](../../en/features/approval-gate.md)。 |
| 权限 | 连接器或提供方需要授权。卡片会要求该提供方所需的字段。 |
| 澄清 | 代理提出一个直接问题并等待回答。 |
| 计划审阅 | 代理提出计划。你可以批准、拒绝，或提供反馈要求修改。 |

后台或定时轮次没有人可以询问。实时聊天之外产生的审批请求会收集到一个待处理列表中，供你之后决定。十分钟内未决定的请求会被拒绝。

## 子代理

轮次委派工作时，每个子代理都有自己的卡片。卡片包含嵌套对话记录、状态、子代理等待你回复时使用的输入框，以及取消按钮。委派是异步的，因此父代理可以继续工作，同时卡片逐步显示结果。分离运行的后台代理、定时任务和记忆同步会收集在单独的收件箱卡片中，不会打断当前线程。

## 代理生成的文件

代理为你生成的内容（例如文档、演示稿、图片或渲染结果）会成为一个产物。输入框上方的标签会打开面板，你可以下载、在所在文件夹中查看或删除。只有已完成的产物会在重启后保留。失败的产物可以重试。

## 工作流提案

如果你要求自动化，代理会提出一个图。提案只会经过验证，不会立即保存。卡片会显示节点列表，并提供三个选项：保存并启用、忽略，或在画布中打开。只有通过这张卡片才能将提案保存为自动化。参见[工作流](../../en/features/workflows.md)。

## 对话线程

侧边栏会列出你的对话。你可以新建、选择、重命名和删除对话（删除前会要求确认）。不同线程可以同时运行，因此某个对话中的耗时任务不会阻塞其他对话。

线程可以包含代理设置的目标和待办清单。它们会以固定列表和显示 token 预算的横幅呈现。目前还不能在界面中编辑它们。

长对话会被压缩，而不是截断。压缩会封存之前的内容，并开始一个指向已封存内容的新一代记录。磁盘上的内容不会删除，但模型只会读取最新一代。目前没有浏览旧代记录的界面。

在 Web 聊天中，附件以带类型的内容部分传递。核心会把上传内容保存在持久化用户消息记录中，并通过受作用域限制的不透明引用访问；消息引用不使用本地文件路径或 base64 数据。轮次运行时，受信任的主机会解析这些引用，并将支持的图片、音频、视频或文件内容交给模型路由。语音便笺会在对话中保留带类型的音频和转写元数据，因此重新加载后仍可播放；听写只发送文本。

聊天主机负责自己的 RPC 和 socket 接口、输入与审批策略、会话检出以及回复的持久化投递。TinyAgents 提供通用轮次准入和排队机制。TinyChannels 提供规范的带类型 Web 事件契约和输出投影，并与 TUI 及中继 Web 进度共用。

## 键盘快捷键

| 快捷键 | 操作 |
| --- | --- |
| `⌘K` / `⌘P` | 打开命令面板 |
| `⌘N` | 新建对话 |
| `⌘F` | 在当前对话中查找 |
| `⌘B` | 切换侧边栏 |
| `⌘,` | 打开设置 |
| `⌘/` 或 `?` | 显示快捷键列表 |

## 尚未提供的功能

侧边栏目前没有线程搜索、置顶、文件夹或归档功能。界面暂时不能设置线程目标或勾选待办事项，也不能浏览压缩后的历史代。界面中有后续建议标签，但目前没有内容生成它们，因此这一行会保持为空。
